# DualGuard EA — полная таблица входных параметров

## Профиль инструмента

| Параметр | По умолчанию | Описание |
|---|---|---|
| `InpProfile` | `PROFILE_AUTO` | Профиль: `auto` (определить по символу), `eurusd`, `gold`. Суффиксы брокера (`EURUSD.a`, `XAUUSDm`, `GOLD`) распознаются по валютам символа и имени. При несоответствии профиля символу новые сделки запрещаются, причина пишется в журнал |
| `InpMagicNumber` | 0 | MagicNumber экземпляра. 0 = авто: EURUSD → 510001, золото → 510002 |
| `InpPartnerMagic` | 0 | MagicNumber второго графика (для общего риска). 0 = авто: противоположный из пары 510001/510002 |
| `InpVerboseLog` | true | Подробный журнал причин каждого разрешённого/заблокированного входа |

## Риск на сделку и лимиты

| Параметр | По умолчанию | Описание |
|---|---|---|
| `InpRiskPercentEURUSD` | 0.5 | Риск на сделку EURUSD, % equity. Лот считается через `OrderCalcProfit` от фактической дистанции SL |
| `InpRiskPercentGold` | 0.3 | Риск на сделку XAUUSD, % equity |
| `InpMaxLot` | 1.0 | Жёсткий потолок лота одной сделки |
| `InpMaxPositionsPerSymbol` | 3 | Максимум открытых позиций советника на инструмент |
| `InpMaxPortfolioRiskPercent` | 2.0 | Максимум суммарного открытого риска (сумма дистанций до SL в деньгах) позиций робота на обоих инструментах, % equity |
| `InpMinAddDistanceATR` | 0.5 | Минимальное расстояние между входами одного направления, в ATR (защита от наслаивания) |

## Общий риск двух графиков (Global Variables)

| Параметр | По умолчанию | Описание |
|---|---|---|
| `InpDailyLossLimitPercent` | 3.0 | Дневной лимит убытка от баланса начала дня, с учётом плавающего убытка (по equity). Срабатывание: закрытие всех позиций робота на обоих инструментах + блокировка до следующего торгового дня. Состояние общее для двух графиков |
| `InpSharedBasketStopPercent` | 5.0 | Общий корзинный стоп: совокупный плавающий убыток позиций робота (оба инструмента) в % equity. Закрывает всё и включает паузу |
| `InpBasketTakeProfitPercent` | 0.5 | Корзинная фиксация прибыли: когда суммарный плавающий плюс позиций робота достигает этого % equity — все позиции закрываются одновременно (асинхронные запросы), паузы нет. 0 = выключено |
| `InpBasketPauseMinutes` | 60 | Пауза после срабатывания корзинного стопа |
| `InpIncludeManualPositions` | false | Учитывать ли ручные сделки (magic 0) в общем контроле. По умолчанию ручные сделки и чужие советники не затрагиваются |
| `InpFastBasketClose` | true | Быстрое закрытие корзины: запросы уходят на сервер асинхронно, позиции закрываются почти одновременно |

## Сигнал входа (M5, только закрытая свеча)

| Параметр | По умолчанию | Описание |
|---|---|---|
| `InpEntryMode` | `ENTRY_TREND` | Режим входа: тренд (EMA+RSI, ядро Nyao Scalper), отбой от полос Боллинджера (идея Dark Venus, без мартингейла), оба |
| `InpBBPeriod` / `InpBBDeviation` | 20 / 2.0 | Параметры полос Боллинджера для режима «отбой» |
| `InpBBRSIBuyBelow` / `InpBBRSISellAbove` | 40 / 60 | Подтверждение RSI для отбоя от полос |
| `InpEMAFastPeriod` / `InpEMASlowPeriod` | 20 / 50 | EMA тренда на M5 |
| `InpRSIPeriod` | 14 | Период RSI |
| `InpRSIBuyMin`..`InpRSIBuyMax` | 50..70 | Зона RSI для покупки (не покупать перекупленность) |
| `InpRSISellMin`..`InpRSISellMax` | 30..50 | Зона RSI для продажи |
| `InpATRPeriod` | 14 | Период ATR (используется для SL/TP/трейлинга/спреда) |
| `InpATRAvgLookback` | 20 | Свечей для средней ATR |
| `InpMinVolRatio` | 0.6 | Фильтр «мёртвого рынка»: ATR/средняя ATR должен быть не ниже. 0 = выкл |

## Фильтр направления H1

| Параметр | По умолчанию | Описание |
|---|---|---|
| `InpUseH1TrendFilter` | true | EMA 50/200 на H1: покупки только когда EMA50>EMA200, продажи — наоборот |
| `InpH1EMAFast` / `InpH1EMASlow` | 50 / 200 | Периоды EMA H1 |

## Профиль EURUSD

| Параметр | По умолчанию | Описание |
|---|---|---|
| `InpEurSLatr` / `InpEurTPatr` | 1.2 / 1.8 | SL и TP в ATR |
| `InpEurTrailATR` / `InpEurBEatr` | 1.0 / 0.8 | Трейлинг и порог безубытка в ATR |
| `InpEurMaxSpreadPoints` | 15 | Максимальный спред в пунктах (0 = авто от ATR) |
| `InpEurMaxSpreadATRRatio` | 0.25 | Авто-порог спреда как доля ATR |
| `InpEurUseSessions` | false | Ограничивать сессии для EURUSD |
| `InpEurNewsMinutes` | 30 | Блок новостей high-impact США и еврозоны, ± минут |

## Профиль XAUUSD (золото)

| Параметр | По умолчанию | Описание |
|---|---|---|
| `InpGoldSLatr` / `InpGoldTPatr` | 1.5 / 2.2 | SL и TP **только от ATR** — фиксированных пунктов нет |
| `InpGoldTrailATR` / `InpGoldBEatr` | 1.0 / 0.8 | Отдельные ATR-множители трейлинга и безубытка |
| `InpGoldMaxSpreadATRRatio` | 0.20 | Запрет входа при спреде больше 0.20 × ATR(14) M5 |
| `InpGoldNewsMinutes` | 45 | Блок новостей США high-impact, ± минут. Меньше 45 задать нельзя (жёсткое правило в коде) |
| `InpGoldUseSessions` | true | Торговля только Лондон + Нью-Йорк, азиатская сессия отключена |
| `InpGoldSessionStartLondon` | 08:00 | Начало торговли (лондонское время, летнее время учитывается автоматически) |
| `InpGoldSessionEndNewYork` | 17:00 | Конец торговли (нью-йоркское время) |

## Время и закрытие недели

| Параметр | По умолчанию | Описание |
|---|---|---|
| `InpTesterUTCOffsetHours` | 2 | Смещение серверного времени от UTC — используется ТОЛЬКО в тестере (на живом графике время берётся из `TimeGMT()`) |
| `InpMinutesBeforeWeekClose` | 40 | Не открывать сделки за N минут до закрытия рынка в пятницу |
| `InpNewsFailOpen` | false | Разрешить торговлю золотом, когда календарь MT5 недоступен. По умолчанию — безопасный отказ (входы блокируются) |

## ИИ-мост

| Параметр | По умолчанию | Описание |
|---|---|---|
| `InpEnableAI` | true | Включить ИИ-ограничитель. В тестере отключается автоматически |
| `InpBridgeURL` | `http://127.0.0.1:8080` | Адрес моста. Обязательно добавить в разрешённые WebRequest |
| `InpBridgePollMinutes` | 30 | Период опроса моста (по таймеру, не на тиках) |
| `InpAICacheTTLMinutes` | 45 | Срок жизни последнего корректного ответа. После истечения режим считается `chaos`, новые входы блокируются |
| `InpBridgeFailureMode` | `BRIDGE_PAUSE` | Если мост **ни разу** не отвечал: `pause` — блокировать входы, `baseline` — работать по локальной логике без ИИ |

## Как ИИ влияет на торговлю (и как не влияет)

| Ответ ИИ | Действие советника |
|---|---|
| `chaos` или `trade_allowed=false` | Новые сделки запрещены |
| `trend_up` | Продажи запрещены |
| `trend_down` | Покупки запрещены |
| `range` | Направления не меняются, применяется `risk_multiplier` |
| `risk_multiplier` | Только уменьшает лот (0.0–1.0) |

ИИ **никогда** не может: увеличить риск, расширить установленный SL,
отменить дневной лимит, открыть сделку в обход локальных фильтров.
