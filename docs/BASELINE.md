# Как проверить стратегию на прошлом — по шагам

Инструкция для владельца. Программировать ничего не нужно, редактировать
файлы тоже.

Смысл всей затеи: до сих пор настройки менялись по рассуждениям («так
логичнее»). Чтобы менять их по числам, нужны настоящие свечи вашего брокера
за долгий срок. Их надо один раз выгрузить.

---

## Шаг 1. Откройте программу и подключитесь к счёту

Обычный запуск. На вкладке **«Обзор»** должно быть видно, что счёт подключён
и баланс показывается. Если счёта нет — сначала вкладка **«Брокер»**.

## Шаг 2. Подготовьте графики в MetaTrader

Это единственный шаг, где нужен сам MetaTrader.

1. Вкладка **«Система»** → кнопка **«Показать терминал»**.
2. В MetaTrader откройте график **EURUSD**, период **M5**
   (кнопка M5 на верхней панели).
3. **Прокрутите график влево** мышью или клавишей `Home` — до самого начала.
   Так терминал скачивает историю с сервера брокера. Без этого он отдаст
   только последние несколько дней.
4. То же самое для **XAUUSD**, тоже **M5**.
5. Дождитесь, пока внизу графика перестанет мигать «загрузка».

Чем дальше прокрутите — тем больше истории будет и тем надёжнее проверка.
Ориентир: хотя бы год.

## Шаг 3. Нажмите одну кнопку

Вкладка **«Система»** → раздел **«История для проверки стратегии»** →
кнопка **«Выгрузить историю»**.

Программа сама заберёт свечи и положит их рядом с собой. Займёт до минуты.
Рядом с кнопкой появится, сколько свечей получилось.

*Если удобнее из командной строки — та же работа делается командой:*

```
AI_Scalper_Pro.exe --export-history
```

## Шаг 4. Проверьте, что файлы появились

Рядом с программой появится папка **history**, а в ней **raw**:

```
history/raw/EURUSD_M5.csv
history/raw/EURUSD_M5.meta.json
history/raw/XAUUSD_M5.csv
history/raw/XAUUSD_M5.meta.json
```

Файл `.csv` — сами свечи. Файл `.meta.json` — паспорт данных: брокер, сервер,
часовой пояс, размер пункта, цена пункта. Он нужен не меньше свечей, не
удаляйте его.

**Никуда перекладывать файлы не надо.** Они уже там, где нужно.

## Шаг 5. Пришлите папку `history` мне

Заархивируйте папку **history** и пришлите. Дальше считаю я.

Внутри только котировки. Ни паролей, ни ключей, ни номеров карт там нет —
номер счёта и имя брокера есть, и это всё.

## Шаг 6. Одна команда для расчёта

Если захотите посчитать сами:

```
python run_baseline.py
```

Считает по EURUSD и XAUUSD **раздельно**, печатает статистику и честно
говорит `UNKNOWN`, если сделок меньше сотни.

Быстрее, по последним 50 000 свечам:

```
python run_baseline.py --bars 50000
```

---

## Что делает программа с данными

**Проверяет их, прежде чем считать.** Плохие данные дают плохой ответ,
который выглядит так же убедительно, как хороший. Проверяется:

| Что | Почему это важно |
|---|---|
| Порядок свечей | Перепутанный порядок = прошлое после будущего |
| Повторы | Одна свеча дважды = лишняя сделка и завышенная статистика |
| Пропуски | Считаются и показываются. **Не дорисовываются** — дорисованная свеча это выдуманные данные |
| Незакрытая последняя свеча | Кусок будущего внутри данных |
| Часовой пояс | Без него нельзя определить сессию и сопоставить свечу с новостью |
| Битые цены | Максимум ниже минимума, нули, отрицательные значения |

**Сырое и обработанное хранятся отдельно.** `history/raw` не меняется никогда,
чтобы всегда можно было вернуться к исходнику.

## Чего проверка на прошлом НЕ покажет — читать обязательно

Числа из проверки не равны будущей прибыли. Вот честный список того, что
воспроизвести невозможно, и это **не заменено выдумкой** — просто отключено
и посчитано как ноль:

* **ИИ.** Его ответов за прошлый год не существует, их никто не сохранял.
  Спросить ИИ сегодня про свечу годичной давности — значит показать ему всё,
  что случилось после неё. Это и есть заглядывание в будущее.
* **Новости.** Календарь отдаёт будущие события, а не снимок того, что было
  известно тогда.
* **Сигналы Telegram.** История чужих сигналов не хранится.
* **Проскальзывание, реквоты, отказы брокера.** В свечах этого нет. Реальный
  результат будет **хуже** показанного.
* **Ведение сделки внутри свечи.** Известны только четыре цены свечи. Если
  внутри одной свечи задет и стоп, и цель — что сработало раньше, неизвестно.
  Берётся **худший** вариант: сначала стоп. Обманывать себя в свою пользу на
  своих же деньгах — плохая привычка.

---

## Чем это отличается от «просто прогнать в тестере MetaTrader»

Тестер MetaTrader проверяет **советник**. А торгует у вас **программа на
Python**, и логика у неё своя. Здесь по истории прогоняется ровно тот код,
который торгует вживую: те же функции счёта сигнала, те же фильтры, тот же
расчёт объёма, тот же трейлинг.

Отдельной «упрощённой стратегии для проверки» не существует. Если бы она
существовала — проверялась бы она, а не то, чем вы торгуете.
