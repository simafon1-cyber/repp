## 1. ЗАМЕЧАНИЕ

P1-H1 и P1-H2 приняты. Осталось одно, не блокирующее:

> Ключ `desktop_app.py --export-history` создаёт каталог снимка и не
> теряет прежние данные. Но, в отличие от принятого `history_export.py`,
> он: (1) не ограничивает экспорт только заданным `H1` и запускает все
> таймфреймы по умолчанию; (2) не имеет `try/finally` для
> `mt5c.disconnect()`; (3) возвращает `0` после `export_all()` без
> проверки пустого или частично ошибочного отчёта.

Замечание справедливо, и причина у всех трёх пунктов одна: **я оставил
вторую копию выгрузки.** Починил основной путь, а рядом лежала похожая
копия, которой починка не досталась.

Две похожие копии расходятся всегда. Вопрос только в том, когда это
заметят.

## 2. КАК БЫЛО

`desktop_app.py`:

```python
    if "--export-history" in sys.argv:
        import history_export
        mt5c.connect()
        снимок = history_export.новый_снимок()
        print(f"Снимок: {снимок}")
        print(history_export.describe(history_export.export_all(
            progress=lambda t: print(t, flush=True), folder=снимок)))
        history_export.записать_манифест(снимок)
        ...
        sys.exit(0)
```

### Чем это било, по шагам

1. Человек запускает программу с ключом `--export-history`.
2. Выгружаются **все четыре** таймфрейма — минуты работы терминала и
   место на диске там, где обычно нужен один.
3. Если выгрузка обрывается посреди — `disconnect()` не вызывается.
   Подключение остаётся занятым, и следующий запуск объяснит это
   как-нибудь иначе. Человек будет искать не там.
4. `sys.exit(0)` стоит безусловно. Ни один инструмент не выгрузился —
   **код всё равно ноль**. Это ровно та же беда, за которую аудит уже
   ловил меня в P1-H1: молчаливый успех там, где ничего не произошло.

## 3. КАК СТАЛО

Не «починил вторую копию», а **убрал вторую копию**. Общая сердцевина
вынесена в `history_export.выгрузить()`:

```python
def выгрузить(таймфреймы, символы=None, bars=None, folder: str = "",
              печать=print) -> tuple:
    """ОДНА сердцевина для всех путей выгрузки. (код, папка_снимка, отчёты).
    ...
    Две похожие копии расходятся всегда. Вопрос только в том, когда это
    заметят. Поэтому сердцевина здесь одна, а пути — только обёртки над
    ней."""
```

Она делает всё, что требовалось от обоих путей: проверяет таймфреймы,
подключается, создаёт снимок, выгружает, печатает каждый файл, пишет
манифест, **отпускает терминал в `finally`** и считает код возврата.

Возврат тройкой `(код, папка, отчёты)` сделан нарочно: обёртке нужна
папка, чтобы отправить именно её. Если бы папку приходилось угадывать
заново, у двух путей опять появились бы разные представления о том, куда
легли файлы.

Теперь оба пути — тонкие обёртки:

```python
def main(аргументы=None) -> int:
    а = _разбор(аргументы)
    код, _, _ = выгрузить(а.timeframe, а.symbol, а.bars, а.folder,
                          печать=lambda т: print(т, flush=True))
    return код
```

```python
        тфы = [sys.argv[i + 1] for i, а in enumerate(sys.argv)
               if а in ("--timeframe", "-t") and i + 1 < len(sys.argv)]
        if not тфы:
            print("Назовите таймфрейм: --timeframe H1 (можно повторять).")
            sys.exit(2)

        код, снимок, _ = history_export.выгрузить(
            тфы, печать=lambda t: print(t, flush=True))
        ...
        sys.exit(код)
```

### Три пункта замечания — построчно

| Пункт | Как закрыт |
|---|---|
| Не ограничивал таймфреймы | Ключ **требует** `--timeframe`, как и основная команда; без него код `2` |
| Нет `try/finally` для `disconnect()` | `finally` внутри сердцевины — один на оба пути |
| Всегда возвращал `0` | `sys.exit(код)`; отправка на GitHub идёт **только при коде 0** |

Последнее отдельно: раньше файлы уезжали на GitHub безусловно. Теперь
отправляется только то, что действительно выгрузилось — иначе в ветке
данных оседал бы неполный снимок, выглядящий как полный.

## 4. ПРОВЕРКА «НАОБОРОТ» — С ЧИСЛАМИ

Исходное: **48 из 48, сбоев 0**. Восстановление — копированием файлов.

| Что сломал | Стало | Что упало |
|---|---|---|
| Вернул ключу свою копию выгрузки | 47 из 48, сбоев 1 | «Запасной ключ зовёт общую сердцевину → []» |
| Сердцевина не возвращает папку | 47 из 48, сбоев 1 | «Возвращён существующий каталог снимка» |
| Строка таймфрейма разбирается посимвольно | 47 из 48, сбоев 1 | «Строка — один элемент» |

Третья строка — не придирка. Обёртки передают то список, то строку; без
приведения строка `"H1"` разобралась бы в `['H', '1']` и дала бы
бессмысленную ошибку про неизвестный таймфрейм.

## 7. ЧЕГО ЭТО НЕ ДАЁТ

1. **Настоящий терминал.** Подделка отвечает так, как её научили.
2. **Склейку снимков постоянной командой.** По-прежнему **не сделано** —
   та склейка, что уже в архиве, делалась разовым сценарием.
3. **Чтение снимков исследованием.** Всё, что читает историю, смотрит в
   `history/raw`. Снимки лежат отдельно и в прогоны не попадают.
