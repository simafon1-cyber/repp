## 2. P1-H1: Я ДАЛ КОМАНДУ, КОТОРАЯ НИЧЕГО НЕ ДЕЛАЕТ

### Как было

В `docs/РЕВИЗИЯ_ДАННЫХ.md` владельцу было написано:

```
cd ai_scalper_standalone
python3 history_export.py
```

А файл `history_export.py` заканчивался так:

```python
def describe(reports) -> str:
    """Что получилось — человеческими словами."""
    ...
    return "\n".join(строки) or "Ничего не выгружено."
```

И всё. Ни `if __name__ == "__main__"`, ни разбора аргументов, ни
подключения к терминалу, ни вызова `export_all()`.

### Чем это било, по шагам

1. Владелец открывает памятку и набирает команду.
2. Python загружает файл, выполняет определения функций.
3. Доходит до конца файла. Вызывать нечего.
4. Процесс завершается. **Код возврата 0. Ни одного слова на экране.**
5. Владелец видит, что «ошибок не было», и считает, что выгрузил.
6. Данных нет. Узнается это в лучшем случае через несколько шагов.

Проверено у себя до починки:

```
$ python3 history_export.py
ModuleNotFoundError: No module named 'MetaTrader5'
```

На Linux падает на импорте. **На Windows, где библиотека установлена,
падать нечему** — файл просто загрузится и закончится молча.

Молчаливый успех там, где ничего не произошло, опаснее падения: падение
видно сразу.

### Как стало

Настоящая точка входа с пятью свойствами, которые потребовал аудит:

```python
def main(аргументы=None) -> int:
    """Возвращает КОД: 0 — выгрузилось, иначе — нет.

    Ненулевой код при пустом отчёте обязателен: без него сценарий,
    вызвавший выгрузку, не отличит «ничего не вышло» от «всё хорошо»."""
```

| Требование аудита | Как выполнено |
|---|---|
| подключается к MT5 | `mt5c.connect()`, код `3` при неудаче |
| принимает только названные таймфреймы | `--timeframe` **обязателен**; неизвестный — код `2` |
| показывает каждый путь и число баров | печатается по каждому инструменту |
| ненулевой код при ошибке или пустом отчёте | коды `2…7`, по причинам |
| отключается в `finally` | да, вокруг всей выгрузки |

Коды разные нарочно: `5` — пусто, `6` — ни один не вышел, `7` — часть с
ошибками. Один общий код не дал бы понять, что случилось.

## 3. P1-H2: ПРАВИЛО БЫЛО В ДОКУМЕНТЕ, А НЕ В КОДЕ

Это то же самое, за что аудит уже ловил меня в демо-приёмке: требование
записано словами, а исполнить его нечем.

### Как было

```python
    csv_file = raw_path(symbol, timeframe, folder)
    os.makedirs(os.path.dirname(csv_file), exist_ok=True)
    with open(csv_file, "w", encoding="utf-8", newline="") as f:
```

Постоянное имя, режим `"w"`. А кнопка в окне звала `export_all()` вообще
без указания папки — то есть прямо в `history/raw`.

### Чем это било

Терминал отдаёт не «всю историю», а **фиксированное число последних
баров**. Поэтому каждая выгрузка сдвигает окно вперёд и теряет начало.
Проверено на живых данных владельца:

| Файл | Начало было | Стало | Потеряно |
|---|---|---|---|
| `EURUSD_M5` | 2025-12-11 | 2025-12-18 | **6 дней** |
| `EURUSD_M15` | 2025-08-15 | 2025-08-20 | 4 дня |

Вернуть потерянное нельзя ничем. И именно кнопка в окне — тот путь,
которым это и происходило.

### Как стало

**Три рубежа, а не один.**

**Первый — каталог с датой, и отказ при совпадении имени:**

```python
def новый_снимок(folder: str = "", когда=None) -> str:
    """Создать НОВЫЙ каталог снимка. Отказ, если такой уже есть.

    Отказ, а не «допишем туда же»: одинаковое имя означает, что рядом
    лежит чужая выгрузка, и дописывать в неё — тот же способ потерять
    данные, только медленнее."""
    ...
    if os.path.exists(путь):
        raise FileExistsError(...)
```

**Второй — запрет писать поверх существующего файла**, на случай любого
другого пути в коде:

```python
    if os.path.exists(csv_file) and not перезаписывать:
        итог["error"] = (
            f"файл уже есть и не перезаписывается: {csv_file}. "
            f"Терминал отдаёт скользящее окно, поэтому повторная выгрузка "
            f"затёрла бы начало истории, вернуть которое нельзя. ...")
        return итог
```

Именно отказ, а не предупреждение в журнал: предупреждение в длинном
выводе не читают, а данные пропадают навсегда.

**Третий — манифест с отпечатком каждого файла.** «Неизменяемый каталог»
без отпечатков — только слово.

**И главное: кнопка в окне переведена на снимки.** Защита бесполезна,
если основной путь её обходит.

Старая папка `history/raw` при этом **не трогается**: то, что в ней уже
лежит, остаётся на месте, и всё, что её читает, продолжает работать.

## 6. ЧЕГО ЭТИ ТЕСТЫ НЕ ПРОВЕРЯЮТ

1. **Настоящий терминал.** Подделка отвечает так, как её научили.
   Сколько лет часовой истории отдаст MetaQuotes-Demo — неизвестно до
   живой выгрузки.
2. **Склейку снимков.** Аудит предложил сделать её отдельной явной
   командой, которая создаёт новый архив и никогда не меняет исходные
   снимки. **Не сделано.** Та склейка, что уже выполнена, делалась
   разовым сценарием, и её правило записано в `data/history_all.tar.gz`
   и в отчёте. Постоянной команды пока нет.
3. **Чтение снимков исследованием.** Всё, что читает историю, по-прежнему
   смотрит в `history/raw`. Снимки лежат отдельно и в прогоны не
   попадают. Это осознанно: смешивать окна в одном чтении нельзя без
   правила склейки, а правило — отдельная работа.
