## Задание

Владелец: «Если все окей собирай». То есть: слить проверенную ветку
интерфейса в рабочую и собрать программу.

## Что это за работа

Это **не новая правка кода**. Слияние переносит в рабочую ветку ровно тот
код, который уже описан и сдан двумя отдельными отчётами:

| Отчёт | Что в нём |
|---|---|
| `docs/НА_ПРОВЕРКУ_UI.md` | внешний вид и ясность интерфейса, контраст в трёх темах, честные подписи кнопок закрытия, предупреждения на «Обзоре» |
| `docs/НА_ПРОВЕРКУ_КНОПКИ.md` | нажатие всех кнопок, исправленная кнопка «?», огоньки нажатия, и признание, что первый вариант проверки был неполным |

Оба отчёта теперь лежат в рабочей ветке и проверяются на этой же ревизии.
Новых изменений поведения слияние не вносит.

## Как проверено

Слияние выполнено с `--no-ff`, конфликтов не было.

**Главное:** весь набор тестов прогнан **после слияния**, а не до. Это
существенно: две ветки по отдельности могут быть зелёными, а вместе — нет,
потому что каждая правила общие файлы (`desktop_app.py`, `tests/run_all.sh`,
`tests/test_single_instance.py`, `tests/test_silence_and_settings.py`).

```
bash tests/run_all.sh
Пройдено: 5010   Сбоев: 0
Код возврата: 0
```

## Проверка «наоборот»

Отдельной проверки «наоборот» здесь нет и быть не может: **новых тестов эта
работа не добавляет**. Все новые тесты и их обратные проверки описаны в двух
отчётах выше — там для каждого показано, что со сломанным кодом он падает.

## Чего эта работа НЕ проверяет

1. **Как окно выглядит.** Тесты работают с поддельным интерфейсом, картинку
   не видят.
2. **Приносит ли нажатие кнопки пользу.** Проверено только «не падает».
3. **Поведение у настоящего брокера.** Зелёные тесты с поддельным брокером
   **не являются** доказательством поведения у настоящего. Это ограничение
   действует всегда.
4. **Собранную программу никто не запускал на живом счёте.** Проверка запуска
   внутри сборки — это открытие окна на чистой машине Windows без терминала
   MetaTrader.
