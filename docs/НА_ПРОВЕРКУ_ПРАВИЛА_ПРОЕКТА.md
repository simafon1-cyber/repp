Дословно записано: любая законченная правка кода сопровождается отдельным

Там же — таблица обязательных разделов отчёта:

| Раздел | Что в нём |

| Проверка «наоборот» | вернуть старый код и показать падение теста, **с числами** |
| Тест-матрица | сценарий → что проверяется по факту → итог |
| Чего тесты НЕ проверяют | честный список |
| Результаты | вывод прогонов и команды для повторения |
| Изменённые файлы | таблица с назначением каждого |

## 3. ПОЧЕМУ ИМЕННО ТАК

**Почему файл, а не память разговора.** Требование «после каждой правки»
действует бессрочно. Память разговора конечна и обнуляется. Файл в
репозитории читается в начале любой сессии — это единственный способ
выполнить слово «каждой».

**Почему туда же попали остальные правила.** Они уже действовали, но
существовали только в переписке. Правило, которое живёт в переписке,
работает ровно до тех пор, пока кто-то помнит переписку. Особенно это
касается запретов на мартингейл и на `LIVE_TRADING=True`: цена забывания
здесь — деньги.

**Чего в файле сознательно нет.** Ни паролей, ни токенов, ни логинов, ни
путей к учётным данным. Файл лежит в репозитории и виден всем, кто имеет
к нему доступ. Номер демо-счёта указан — он не секрет и уже фигурирует в
переписке; пароля к нему в файле нет и не будет.
