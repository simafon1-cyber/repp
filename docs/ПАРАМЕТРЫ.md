# Все параметры программы — что делает каждый и что будет, если изменить

Разделы этой страницы повторяют вкладки внутри программы:
**Настройка → Торговля / Сигнал / Риск / Защита / AI-сигнал / Обучение**.
Найти параметр можно поиском по имени (Ctrl+F).

То же самое доступно прямо в программе: рядом с каждым полем есть кнопка
**«?»** — она открывает это же описание. Текст один и тот же, здесь он
просто собран в одном месте, чтобы можно было читать подряд.

**Значение по умолчанию** — то, что стоит в программе сразу после
установки. Если сомневаетесь, верните его.

## Содержание

- **Торговля**: Общее, Часы торговли, Лот, Score-фильтр
- **Сигнал**: Индикаторы, Price Action / откат, Объём, Доп. индикаторы, Собственная стратегия, Режим рынка, Контекст рынка, Анти-'зеркало' фильтры, Автонастройка под инструмент
- **Риск**: Стопы / TP, Break Even, Трейлинг-стоп, Profit Lock, Просадка / серии убытков, Издержки, Частичное закрытие, Фиксация прибыли
- **Защита**: Защитные проверки, Новости (пороги)
- **AI-сигнал**: AI-сигнал
- **Обучение**: Автообучение, Автообновление
- **Профиль риска** — отдельная таблица в конце: размер сделки и лимиты счёта

# Вкладка «Торговля»

## Общее

### `POLL_SECONDS`

**Частота опроса рынка, сек**

*тип: целое число · по умолчанию: `5`*

Как часто программа смотрит на рынок и ведёт открытые сделки.

- **Больше / включить.** Реже опрос — меньше нагрузка на компьютер, но вход в сделку и подтягивание стопа происходят позже. На быстром рынке можно опоздать на несколько пунктов.
- **Меньше / выключить.** Чаще опрос — быстрее реакция, но больше запросов к терминалу. Ниже 1 секунды смысла нет: бары M5 всё равно обновляются реже.

### `TIMEFRAME`

**Рабочий таймфрейм**

*тип: выбор из списка · по умолчанию: `'M5'` · варианты: `M1`, `M5`, `M15`, `M30`, `H1`, `H4`, `D1`*

Таймфрейм, на котором ищутся входы. Один бар M5 = 5 минут.

- **Больше / включить.** Старший таймфрейм (M15, H1) — сделок меньше, но они спокойнее и дольше живут.
- **Меньше / выключить.** Младший (M1) — сделок больше, но доля шума резко растёт, а спред съедает бОльшую часть движения.

### `TREND_TIMEFRAME`

**Старший ТФ тренда (должен быть старше рабочего)**

*тип: выбор из списка · по умолчанию: `'M15'` · варианты: `M1`, `M5`, `M15`, `M30`, `H1`, `H4`, `D1`*

Старший таймфрейм: по нему определяется направление тренда, против которого программа старается не входить.

- **Больше / включить.** Чем старше — тем «медленнее» и надёжнее тренд, но реже совпадения с сигналом.
- **Меньше / выключить.** Слишком близкий к рабочему — фильтр перестаёт что-либо фильтровать.

> ⚠️ **Внимание.** Обязан быть СТАРШЕ рабочего таймфрейма, иначе фильтр бессмысленный.

### `MAGIC_NUMBER`

**Magic number (НЕ менять во время работы бота!)**

*тип: целое число · по умолчанию: `234567`*

Метка, по которой программа узнаёт СВОИ сделки среди всех остальных на счёте.

> ⚠️ **Внимание.** НЕ меняйте при открытых позициях: программа перестанет их видеть, и они останутся без стопов, трейлинга и учёта в лимитах.

### `LOG_LEVEL`

**Уровень логирования**

*тип: выбор из списка · по умолчанию: `'INFO'` · варианты: `DEBUG`, `INFO`, `WARNING`, `ERROR`*

Насколько подробно писать журнал.

- **Больше / включить.** DEBUG — видно каждое решение, полезно при разборе проблем, но файл растёт быстро.
- **Меньше / выключить.** WARNING — только проблемы. Журнал маленький, но разобраться потом сложнее.

### `LOG_CSV_PATH`

**Имя CSV-файла журнала сделок**

*тип: текст · по умолчанию: `'trades_log.csv'`*

Имя файла, куда пишется история сделок программы.

> ⚠️ **Внимание.** Этот файл — ваши данные, в облако он не отправляется.

## Часы торговли

### `USE_TRADING_HOURS`

**Ограничить торговлю часами (иначе круглосуточно)**

*тип: галочка · по умолчанию: `False`*

Ограничить торговлю определёнными часами.

- **Больше / включить.** Включено — бот работает только в заданном окне. Полезно, если не хотите торговать ночью, когда спреды шире, а движения случайны.
- **Меньше / выключить.** Выключено (по умолчанию) — бот работает круглосуточно, всю торговую сессию.

### `TRADING_START_HOUR`

**Час начала торговли, 0-23 (время сервера)**

*тип: целое число · по умолчанию: `8`*

Час, с которого разрешена торговля. Время СЕРВЕРА брокера, а не вашего компьютера.

- **Больше / включить.** Позже начало — пропускаете азиатскую сессию, где движения обычно вялые.
- **Меньше / выключить.** Раньше начало — больше времени работы, но и больше сделок в тонком рынке.

> ⚠️ **Внимание.** Действует только при включённом «Ограничить торговлю часами».

### `TRADING_END_HOUR`

**Час окончания торговли, 0-23 (время сервера)**

*тип: целое число · по умолчанию: `20`*

Час, после которого новые сделки не открываются. Уже открытые продолжают вестись.

- **Больше / включить.** Позже окончание — захватываете американскую сессию и её волатильность.
- **Меньше / выключить.** Раньше окончание — уходите до вечерних движений.

> ⚠️ **Внимание.** Если начало больше окончания (например 22 и 6), окно считается через полночь.

## Лот

### `USE_RISK_BASED_LOT`

**Считать лот по риску в % от эквити (иначе фиксированный)**

*тип: галочка · по умолчанию: `True`*

Считать объём сделки от риска в процентах от счёта.

- **Больше / включить.** Включено (по умолчанию) — объём подбирается так, чтобы потеря по стопу равнялась заданному проценту. Чем шире стоп, тем МЕНЬШЕ лот. Это главный механизм защиты счёта.
- **Меньше / выключить.** Выключено — всегда торгуется фиксированный лот из настройки ниже, независимо от расстояния до стопа. На широком стопе потеря будет во много раз больше обычной.

### `LOT_FALLBACK`

**Фиксированный / запасной лот**

*тип: число · по умолчанию: `0.01`*

Фиксированный объём, если расчёт по риску выключен.

- **Больше / включить.** Больше лот — больше и прибыль, и убыток, пропорционально.
- **Меньше / выключить.** Меньше лот — меньше риск. Ниже минимального лота брокера (обычно 0.01) опуститься нельзя.

## Score-фильтр

### `USE_SCORE_FILTER`

**Входить только по score-порогу профиля**

*тип: галочка · по умолчанию: `True`*

Входить только когда общая оценка сигнала набрала порог профиля.

- **Больше / включить.** Включено — сделка открывается лишь при достаточно качественном сигнале.
- **Меньше / выключить.** Выключено — порог не проверяется, входов станет заметно больше, качество упадёт.

> ⚠️ **Внимание.** Выключать не рекомендуется: это основной фильтр качества входа.

# Вкладка «Сигнал»

## Индикаторы

### `EMA_FAST_PERIOD`

**EMA быстрая — период**

*тип: целое число · по умолчанию: `20`*

Период быстрой скользящей средней. Показывает ближайшее направление.

- **Больше / включить.** Больше период — линия глаже, меньше ложных сигналов, но реакция запаздывает.
- **Меньше / выключить.** Меньше период — реакция быстрее, но много ложных пересечений на шуме.

### `EMA_SLOW_PERIOD`

**EMA медленная — период**

*тип: целое число · по умолчанию: `50`*

Период медленной скользящей. Вместе с быстрой задаёт направление.

- **Больше / включить.** Больше — фильтр строже, сделок меньше.
- **Меньше / выключить.** Меньше — сигналы чаще, но менее надёжны.

> ⚠️ **Внимание.** Должен быть заметно больше быстрой EMA, иначе они сливаются.

### `EMA_TREND_PERIOD`

**EMA тренда (старший ТФ) — период**

*тип: целое число · по умолчанию: `200`*

Период скользящей на СТАРШЕМ таймфрейме — общий тренд.

- **Больше / включить.** Больше (200 и выше) — учитывается только крупное направление.
- **Меньше / выключить.** Меньше — фильтр реагирует на среднесрочные колебания и чаще меняет мнение.

### `ADX_PERIOD`

**ADX — период**

*тип: целое число · по умолчанию: `14`*

Период индикатора силы тренда ADX.

- **Больше / включить.** Больше — оценка силы плавнее и запаздывает.
- **Меньше / выключить.** Меньше — дёргается на каждом всплеске.

### `RSI_PERIOD`

**RSI — период**

*тип: целое число · по умолчанию: `14`*

Период RSI — показывает, есть ли запас хода до перекупленности.

- **Больше / включить.** Больше — сглаженнее, реже крайние значения.
- **Меньше / выключить.** Меньше — чаще заходит в зоны перекупленности и перепроданности.

### `ATR_PERIOD`

**ATR — период**

*тип: целое число · по умолчанию: `14`*

Период ATR — средний размах цены. От него считаются стоп, цель и почти все пороги в пунктах.

- **Больше / включить.** Больше — ATR устойчивее, стопы стабильнее по размеру.
- **Меньше / выключить.** Меньше — ATR резко скачет, а вместе с ним и размер стопа от сделки к сделке.

> ⚠️ **Внимание.** ATR влияет почти на всё. Менять стоит осторожно и по одному шагу.

### `ATR_AVG_PERIOD`

**ATR — период среднего**

*тип: целое число · по умолчанию: `20`*

За сколько баров считать СРЕДНИЙ ATR — с ним сравнивается текущий, чтобы заметить всплеск волатильности.

- **Больше / включить.** Больше — среднее спокойнее, всплески заметнее.
- **Меньше / выключить.** Меньше — среднее само подстраивается под всплеск, и защита срабатывает реже.

### `ADX_MIN_LEVEL`

**ADX — минимальный уровень тренда**

*тип: целое число · по умолчанию: `25`*

Ниже какого ADX тренд считается слабым.

- **Больше / включить.** Выше порог — входим только в сильный тренд, сделок меньше.
- **Меньше / выключить.** Ниже порог — торгуем и в вялом рынке, где ложных сигналов больше.

### `RSI_OVERBOUGHT`

**RSI — уровень перекупленности**

*тип: целое число · по умолчанию: `70`*

Уровень перекупленности. Чем ближе RSI к нему, тем меньше баллов получает покупка.

- **Больше / включить.** Выше (80) — покупки разрешены даже на разогретом рынке.
- **Меньше / выключить.** Ниже (60) — покупки отсекаются рано, сделок меньше.

### `RSI_OVERSOLD`

**RSI — уровень перепроданности**

*тип: целое число · по умолчанию: `30`*

Уровень перепроданности. Зеркально предыдущему, но для продаж.

- **Больше / включить.** Выше (40) — продажи отсекаются рано.
- **Меньше / выключить.** Ниже (20) — продажи разрешены даже на сильно упавшем рынке.

## Price Action / откат

### `PULLBACK_TOLERANCE_POINTS`

**Допуск отката, пункты**

*тип: целое число · по умолчанию: `50`*

Насколько глубоко цена должна откатиться к скользящей, чтобы откат засчитался.

- **Больше / включить.** Больше допуск — засчитывается больше откатов, входов больше.
- **Меньше / выключить.** Меньше — только точные касания, входов мало, но они чище.

> ⚠️ **Внимание.** Авто-масштабируется под ATR инструмента, если включена автонастройка.

### `BODY_PERCENT_MIN`

**Мин. % тела свечи**

*тип: целое число · по умолчанию: `60`*

Какую долю свечи должно занимать тело, чтобы считать её подтверждающей.

- **Больше / включить.** Выше (80) — только уверенные свечи, входов меньше.
- **Меньше / выключить.** Ниже (40) — подходит почти любая свеча, подтверждение теряет смысл.

### `MAX_WICK_PERCENT`

**Макс. % тени свечи**

*тип: целое число · по умолчанию: `30`*

Какая максимальная тень допустима у подтверждающей свечи. Длинная тень против входа означает, что цену уже отбили.

- **Больше / включить.** Выше — допускаются свечи с длинными тенями, риск входа перед разворотом растёт.
- **Меньше / выключить.** Ниже — строже отбор, сделок меньше.

## Объём

### `USE_VOLUME_FILTER`

**Учитывать тиковый объём**

*тип: галочка · по умолчанию: `False`*

Учитывать тиковый объём при оценке сигнала.

- **Больше / включить.** Включено — сигналы на всплеске активности получают больше баллов.
- **Меньше / выключить.** Выключено (по умолчанию) — баллы за объём начисляются всегда. У форекс-брокеров тиковый объём неточен, поэтому фильтр по умолчанию не используется.

### `VOLUME_AVG_PERIOD`

**Период среднего объёма**

*тип: целое число · по умолчанию: `20`*

За сколько баров считать средний объём для сравнения.

- **Больше / включить.** Больше — среднее спокойнее.
- **Меньше / выключить.** Меньше — чувствительнее к разовым всплескам.

## Доп. индикаторы

### `USE_MULTI_INDICATOR`

**Подмешивать MACD/Bollinger/Stochastic в score (multi_indicator.py)**

*тип: галочка · по умолчанию: `True`*

Подмешивать в оценку классические индикаторы: MACD, полосы Боллинджера, стохастик.

- **Больше / включить.** Включено — добавляется независимое мнение, сигналы чуть строже.
- **Меньше / выключить.** Выключено — оценка строится только на основных правилах.

### `MULTI_INDICATOR_WEIGHT`

**Вес группы индикаторов в score**

*тип: целое число · по умолчанию: `12`*

Сколько баллов из 100 может добавить эта группа индикаторов.

- **Больше / включить.** Больше вес — их мнение сильнее влияет на решение.
- **Меньше / выключить.** Меньше — влияние символическое.

### `MACD_FAST_PERIOD`

**MACD: период быстрой EMA**

*тип: целое число · по умолчанию: `12`*

MACD: период быстрой линии.

- **Больше / включить.** Больше — сигналы реже и позже.
- **Меньше / выключить.** Меньше — чаще, но больше ложных.

### `MACD_SLOW_PERIOD`

**MACD: период медленной EMA**

*тип: целое число · по умолчанию: `26`*

MACD: период медленной линии.

- **Больше / включить.** Больше — учитывается более долгое движение.
- **Меньше / выключить.** Меньше — MACD дёргается чаще.

### `MACD_SIGNAL_PERIOD`

**MACD: период сигнальной линии**

*тип: целое число · по умолчанию: `9`*

MACD: период сигнальной линии, пересечение с которой и даёт сигнал.

- **Больше / включить.** Больше — сглаживает, сигналов меньше.
- **Меньше / выключить.** Меньше — сигналов больше, шума тоже.

### `BB_PERIOD`

**Bollinger Bands: период SMA**

*тип: целое число · по умолчанию: `20`*

Полосы Боллинджера: период средней линии.

- **Больше / включить.** Больше — полосы шире и спокойнее.
- **Меньше / выключить.** Меньше — полосы дёргаются за ценой.

### `BB_STD_MULT`

**Bollinger Bands: множитель стандартного отклонения**

*тип: число · по умолчанию: `2.0`*

Насколько широко расставлены полосы Боллинджера.

- **Больше / включить.** Больше (2.5-3) — выход за полосу считается редким событием, сигналов мало.
- **Меньше / выключить.** Меньше (1.5) — цена выходит за полосу постоянно, сигнал теряет ценность.

### `STOCH_K_PERIOD`

**Stochastic: период %K**

*тип: целое число · по умолчанию: `14`*

Стохастик: основной период.

- **Больше / включить.** Больше — плавнее.
- **Меньше / выключить.** Меньше — резче реагирует на развороты.

### `STOCH_D_PERIOD`

**Stochastic: период %D**

*тип: целое число · по умолчанию: `3`*

Стохастик: период сглаживания.

- **Больше / включить.** Больше — меньше ложных пересечений.
- **Меньше / выключить.** Меньше — сигналы раньше, но грязнее.

## Собственная стратегия

### `USE_CUSTOM_STRATEGY`

**Использовать собственную стратегию программы (custom_strategy.py)**

*тип: галочка · по умолчанию: `True`*

Учитывать мнение собственной стратегии программы.

- **Больше / включить.** Включено — стратегия добавляет баллы к оценке.
- **Меньше / выключить.** Выключено — оценка считается без неё.

### `CUSTOM_STRATEGY_WEIGHT`

**Вес собственной стратегии в score**

*тип: целое число · по умолчанию: `15`*

Максимум баллов, которые может добавить стратегия.

- **Больше / включить.** Больше — стратегия сильнее влияет на выбор.
- **Меньше / выключить.** Меньше — её мнение почти не учитывается.

### `MIN_RISK_REWARD_RATIO`

> ⚠️ **Внимание.** Ниже 1.0 опускать нельзя: получите систему, где выигрыш меньше проигрыша.

## Просадка / серии убытков

> ⚠️ **Внимание.** Порог дня — не единственная защита, но без него потери за один день ничем не ограничены сверху. Держите риск на сделку маленьким.

- **Больше / включить.** Включено — при глубокой просадке бот замолкает до перезапуска. Спасает от затяжной серии неудач, но может выключить его посреди дня и не включить обратно самостоятельно.
- **Меньше / выключить.** Выключено (по умолчанию) — бот работает всё торговое время. Убыток ограничивается на КАЖДОЙ сделке (стоп-лосс, риск на сделку, лимит совокупного риска), а не остановкой после.

> ⚠️ **Внимание.** Без этого лимита просадка счёта сверху ничем не ограничена. Держите риск на сделку небольшим и смотрите журнал.

### `MAX_CONSECUTIVE_LOSSES`

**Серия убытков подряд, после которой объём снижается**

*тип: целое число · по умолчанию: `5`*

После скольких убытков подряд по одной паре риск снижается до минимального множителя (а если задана пауза — включается она).

- **Больше / включить.** Больше — реакция на серию наступает позже, объём дольше остаётся полным.
- **Меньше / выключить.** Меньше — объём урезается уже после пары неудач.

### `PAUSE_MINUTES_AFTER_LOSS_STREAK`

**Пауза после серии убытков, минут (0 = без паузы, торговля не прерывается)**

*тип: целое число · по умолчанию: `0`*

- **Больше / включить.** Больше — пара выключается надолго. При 720 (12 часов) торговый день по ней потерян.
- **Меньше / выключить.** 0 (по умолчанию) — бот продолжает работу сразу. Вместо паузы работает снижение объёма: счётчик убытков не обнуляется, пока не придёт прибыльная сделка, и риск держится на нижней границе.

- **Меньше / выключить.** Выключено — объём одинаковый независимо от последних результатов.

**Требовать совпадения направления с AI**

*тип: галочка · по умолчанию: `False`*

Входить только если ИИ согласен с направлением.

- **Больше / включить.** Включено — сделок меньше, каждая подтверждена ИИ. При недоступности ИИ торговля почти остановится.
- **Меньше / выключить.** Выключено (по умолчанию) — несогласие ИИ просто снимает баллы.

### `ANTHROPIC_API_KEY`

**Ключ Claude (console.anthropic.com)**

*тип: секрет*

Ключ доступа к Claude.

> ⚠️ **Внимание.** Это секрет. Не публикуйте его и не присылайте в переписке.

### `OPENAI_API_KEY`

**Ключ OpenAI (нужен только для провайдера openai)**

*тип: секрет*

Ключ доступа к OpenAI. Нужен только если выбран этот провайдер.

> ⚠️ **Внимание.** Это секрет.

### `AI_SIGNAL_TIMEOUT_MS`

**Таймаут запроса к AI, мс**

*тип: целое число · по умолчанию: `3000`*

Сколько ждать ответа ИИ, прежде чем продолжить без него.

- **Больше / включить.** Больше — выше шанс дождаться, но задерживается весь цикл.
- **Меньше / выключить.** Меньше — ИИ чаще не успевает, и решение принимается без него.

# Вкладка «Обучение»

## Автообучение

### `USE_AUTO_LEARNING`

**Адаптировать вес AI / порог по винрейту**

*тип: галочка · по умолчанию: `True`*

Подстраивать вес ИИ и порог входа под свежую статистику.

- **Больше / включить.** Включено — после удачной серии бот входит чуть охотнее, после неудачной — строже.
- **Меньше / выключить.** Выключено — настройки всегда одинаковые.

### `USE_SYMBOL_AUTO_OFF`

**Отключать инструмент, который стабильно в минусе**

*тип: галочка · по умолчанию: `True`*

Инструмент, который стабильно тянет счёт вниз, перестаёт торговаться сам.

- **Больше / включить.** Включено — программа сама отсекает убыточный инструмент, остальные работают как обычно.
- **Меньше / выключить.** Выключено — убыточный инструмент торгуется дальше, пока вы не уберёте его руками.

Отключение не вечное и не требует нажатий: окно последних сделок скользящее,
старые убытки из него выпадают, и торговля по инструменту возобновляется сама.

### `SYMBOL_AUTO_OFF_MIN_TRADES`

**Сколько сделок нужно, прежде чем судить об инструменте**

*тип: целое число · по умолчанию: `10`*

Сколько сделок должно накопиться, прежде чем судить об инструменте.

- **Больше.** Решение надёжнее, но убыток успеет накопиться.
- **Меньше.** Реакция быстрее, но можно отключить пару из-за случайной серии.

### `SYMBOL_AUTO_OFF_LOSS_PERCENT`

**Потерял больше % счёта за окно — отключить инструмент**

*тип: дробное число · по умолчанию: `8.0`*

Сколько процентов счёта инструмент должен потерять за окно последних сделок,
чтобы его отключили. Считается ОТ РАЗМЕРА СЧЁТА: минус 30 при депозите 65 —
катастрофа, при депозите 10 000 — обычный шум.

- **Больше.** Терпим дольше, убыток успевает вырасти.
- **Меньше.** Отключаем раньше, но чаще по случайной полосе.

### `AUTO_LEARNING_WINDOW`

**Окно последних сделок по символу**

*тип: целое число · по умолчанию: `20`*

Сколько последних сделок по паре учитывать.

- **Больше / включить.** Больше — выводы устойчивее, но реагирует медленно.
- **Меньше / выключить.** Меньше — подстраивается быстро, но принимает случайность за закономерность.

### `AUTO_LEARNING_MIN_TRADES`

**Мин. сделок для начала адаптации**

*тип: целое число · по умолчанию: `5`*

Сколько сделок нужно, прежде чем начать подстраиваться.

- **Больше / включить.** Больше — дольше ждём, зато решение опирается на данные.
- **Меньше / выключить.** Меньше — бот начинает «учиться» по двум-трём случайным сделкам.

### `AI_WEIGHT_MULT_MIN`

**Мин. множитель веса AI**

*тип: число · по умолчанию: `0.5`*

Насколько сильно может упасть доверие к ИИ при плохой статистике.

- **Больше / включить.** Ближе к 1.0 — доверие почти не снижается.
- **Меньше / выключить.** Ближе к 0 — после неудач ИИ практически перестаёт учитываться.

### `AI_WEIGHT_MULT_MAX`

**Макс. множитель веса AI**

*тип: число · по умолчанию: `1.5`*

Насколько может вырасти доверие к ИИ при хорошей статистике.

- **Больше / включить.** Больше — на удачной серии ИИ получает много влияния.
- **Меньше / выключить.** Ближе к 1.0 — доверие не растёт.

### `SCORE_THRESHOLD_ADJUST_MIN`

**Мин. коррекция порога score**

*тип: целое число · по умолчанию: `-10`*

Насколько МОЖНО снизить порог входа на удачной серии. Число отрицательное.

- **Больше / включить.** Ближе к 0 — порог почти не смягчается.
- **Меньше / выключить.** Сильно отрицательное — после нескольких удач бот начнёт входить в слабые сигналы.

### `SCORE_THRESHOLD_ADJUST_MAX`

**Макс. коррекция порога score**

*тип: целое число · по умолчанию: `15`*

Насколько можно ПОВЫСИТЬ порог на неудачной серии.

- **Больше / включить.** Больше — после убытков бот резко становится разборчивее и почти перестаёт торговать.
- **Меньше / выключить.** Меньше — неудачи почти не влияют на строгость.

### `USE_TP_LEARNING`

**Учить цель прибыли по пикам прошлых сделок (медиана)**

*тип: галочка · по умолчанию: `True`*

Учить цель прибыли по тому, сколько рынок реально давал.

- **Больше / включить.** Включено — цель берётся из медианы пиков прошлых сделок, а не из настроек.
- **Меньше / выключить.** Выключено — цель всегда считается от ATR.

### `TP_LEARN_FRACTION`

**Доля от медианы пика для TP (0.7 = выходить до разворота)**

*тип: число · по умолчанию: `0.7`*

Какую долю от медианы пика брать за цель.

- **Больше / включить.** Ближе к 1.0 — цель совпадает с типичным пиком, но до неё часто не доходит.
- **Меньше / выключить.** Меньше (0.5) — выходим сильно раньше разворота, зато чаще доходим.

### `TP_LEARN_MIN_POINTS`

**Мин. выученная цель, пункты**

*тип: целое число · по умолчанию: `10`*

Ниже какой цели не опускаться ни при какой статистике.

- **Больше / включить.** Больше — защита от слишком мелких целей.
- **Меньше / выключить.** Меньше — допускаются цели в пределах спреда.

### `TP_LEARN_MAX_POINTS`

**Макс. выученная цель, пункты**

*тип: целое число · по умолчанию: `2000`*

Выше какой цели не подниматься.

- **Больше / включить.** Больше — разрешены очень дальние цели.
- **Меньше / выключить.** Меньше — цель обрезается даже при хорошей статистике.

### `USE_LEARNING_PERSISTENCE`

**Сохранять выученное между запусками (без этого обучение обнуляется при каждом старте)**

*тип: галочка · по умолчанию: `True`*

Сохранять выученное между запусками программы.

- **Больше / включить.** Включено — статистика продолжается после перезапуска.
- **Меньше / выключить.** Выключено — при каждом запуске обучение начинается с нуля. Если вы выключаете компьютер на ночь, обучение не заработает вообще.

### `LEARNING_STATE_PATH`

**Файл со статистикой обучения**

*тип: текст · по умолчанию: `'learning_state.json'`*

Файл, в котором хранится статистика обучения.

> ⚠️ **Внимание.** Удалить файл = сбросить обучение.

# Профиль риска

Эти значения хранятся отдельно для каждого профиля (Консервативный,
Сбалансированный, Агрессивный, Свой) и редактируются на вкладке
**Настройка → Риск** в блоке «Профиль риска». Меняется только выбранный
профиль — остальные остаются как были.

| Поле | Что это | Тип |
|---|---|---|
| `name` | Название профиля | текст |
| `risk_percent` | Риск на сделку, % от эквити | число |
| `atr_sl_multiplier` | Множитель ATR для SL | число |
| `use_money_tp` | TP в деньгах (иначе Risk/Reward) | галочка |
| `target_profit_money` | Целевой TP, деньги | число |
| `min_score_to_trade` | Порог score для входа | целое число |
| `max_open_positions` | Макс. одновременных сделок | целое число |
| `max_trades_per_day` | Макс. сделок в день | целое число |
| `daily_loss_limit_pct` | Дневной порог убытка, % (0 = без порога) | число |
| `max_drawdown_pct` | Лимит просадки, % | число |
| `max_total_risk_pct` | Лимит совокупного риска, % | число |
| `ignore_soft_filters` | Игнорировать мягкие фильтры | галочка |
| `hedge_both_directions` | Хедж: при сигнале открывать сразу BUY и SELL (обычный SL на каждой ноге) | галочка |

Значения по умолчанию для каждого профиля смотрите в
[`config.py.example`](../ai_scalper_standalone/config.py.example), блок
`RISK_PROFILES`.
