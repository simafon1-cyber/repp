# Перенос программы на сервер (Google Cloud и не только)

Ответ на вопрос владельца: «у меня есть Google Cloud, можем туда перенести
программу, чтобы она работала удалённо и запускалась?»

**Коротко: да, можно. Но сначала прочитайте раздел про деньги — вероятно, вам
выгоднее другой вариант.**

---

## Что именно требуется, и почему нельзя проще

Программа не может работать «просто в облаке» как сайт. Три жёстких условия:

1. **Нужна Windows.** Библиотека, через которую программа разговаривает с
   MetaTrader (`MetaTrader5` для Python), существует **только под Windows**.
   Под Linux её нет.
2. **Нужен запущенный терминал MetaTrader 5 рядом.** Программа не ходит к
   брокеру напрямую — она отдаёт команды терминалу, который стоит на той же
   машине. Нет терминала — нет торговли.
3. **Нужен рабочий стол.** И терминал, и наша программа — это окна. Им нужен
   живой сеанс Windows, а не «сервис без экрана».

Отсюда вывод: подходит **только виртуальная машина с Windows**. Cloud Run,
Cloud Functions, App Engine, контейнеры — **не подходят вообще**, там нет ни
Windows, ни рабочего стола.

---

## Деньги: посчитайте до того, как начнёте

Это главное, что стоит понять заранее.

Виртуальная машина с Windows в Google Cloud, которой хватит для терминала и
программы, — это примерно **2 ядра и 4 ГБ памяти** (тип вроде `e2-medium`).
Круглосуточно это выходит ориентировочно в **$45–70 в месяц**: сама машина
плюс отдельная плата за лицензию Windows, плюс диск.

Точную цифру смотрите в калькуляторе Google: цены меняются и зависят от
региона — https://cloud.google.com/products/calculator

Теперь сопоставьте с вашим счётом:

| депозит | сервер в месяц | сколько это от счёта |
|---|---|---|
| $500 | ~$55 | **11% в месяц** |
| $1000 | ~$55 | **5.5% в месяц** |

За год это **66–130% депозита**. То есть сервер должен «отработать» сам себя,
прежде чем вы увидите первую прибыль.

**Бесплатный уровень Google Cloud здесь не поможет:** бесплатная машинка
только с Linux, а лицензия Windows не бесплатна ни при каких условиях.

### Дешевле: Forex VPS

Есть компании, которые сдают именно **Windows-VPS для торговли** — за
**$10–30 в месяц**. Часто у них серверы стоят рядом с площадками брокеров,
то есть задержка до брокера меньше, чем из обычного дата-центра Google.

Многие брокеры дают такой VPS **бесплатно** при депозите от определённой
суммы — спросите у своего брокера, это обычная услуга.

**Что выбрать.** Если Google Cloud у вас уже оплачен по другим причинам или
там остались гранты — используйте его. Если сервер нужен только под эту
программу — Forex VPS дешевле в два-пять раз и ближе к брокеру.

> **Отдельно:** встроенный в MetaTrader «VPS / Виртуальный хостинг» (кнопка
> прямо в терминале, ~$15/мес) для нас **не подойдёт**. Он умеет переносить
> только советники на языке MQL5. Наша программа — отдельное приложение на
> Python рядом с терминалом, туда она не помещается.

## Порядок действий в Google Cloud

### 1. Создать машину

Compute Engine → «Создать экземпляр»:

- **Регион:** ближе к серверу вашего брокера. Для европейских брокеров —
  `europe-west`, для американских — `us-east`. Это влияет на задержку
  исполнения, а для скальпинга задержка важна.
- **Тип машины:** `e2-medium` (2 ядра, 4 ГБ). Меньше не берите: терминал с
  несколькими графиками плюс наша программа в 2 ГБ не поместятся.
- **Загрузочный диск:** Windows Server 2022, диск **50 ГБ**.
- **Брандмауэр:** галочки «разрешить HTTP/HTTPS» **не ставьте**. Они не
  нужны и открывают лишние двери.

### 2. Зайти на машину

В консоли Google Cloud у машины есть кнопка «RDP» → «Задать пароль Windows».
Задайте пароль, скачайте файл подключения и войдите через «Подключение к
удалённому рабочему столу» (есть в любой Windows).

### 3. Поставить терминал и программу

На сервере, внутри Windows:

1. Скачайте и установите MetaTrader 5 вашего брокера.
2. Войдите в торговый счёт, поставьте галочку **«Разрешить автоматическую
   торговлю»** (Сервис → Настройки → Советники).
3. Скачайте нашу программу:
   https://github.com/simafon1-cyber/repp/releases/latest
4. Запустите `AI_Scalper_Pro.exe`, настройте счёт на вкладке «Брокер» или
   «Счета».

### 4. Включить автозапуск

В программе: вкладка **«Система»** → **«Запускать при старте Windows»**.
После этого перезагрузка сервера не оставит вас без торговли.

Проверьте: перезагрузите машину и убедитесь, что и терминал, и программа
поднялись сами.

### 5. Как отключаться — ВАЖНО

Закрывая удалённый рабочий стол, **не нажимайте «Выйти из системы» (Log off)**.
Нажимайте **крестик** или «Отключиться» (Disconnect).

Разница принципиальная: «Выйти» закрывает сеанс Windows, а вместе с ним и все
окна — терминал и программа остановятся, и торговля прекратится. «Отключиться»
оставляет сеанс работать, вы просто перестаёте его видеть.

## Как следить за торговлей с телефона

Здесь ничего доделывать не нужно, в программе это уже есть.

**Веб-дашборд.** Программа поднимает страницу на порту 5000: состояние счёта,
открытые сделки, старт/стоп, включение и выключение пар. Открывается с
телефона.

**Журнал в облаке** (вкладка «Система»): раз в несколько минут программа
выкладывает отчёт по сделкам в ваш закрытый репозиторий GitHub. Открывается
с телефона, компьютер для этого не нужен.

### Безопасность дашборда — прочитайте обязательно

Через дашборд можно **остановить и запустить торговлю**. На домашнем
компьютере он доступен только вашей домашней сети. На сервере с публичным
адресом — всему интернету, если открыть порт.

**Правило первое: задайте пароль дашборда.** Вкладка «Система» → «Пароль
дашборда».

Раньше пустой пароль работал как настоящий: любой, кто прислал правильный
логин, попадал внутрь, — а логин это ваш адрес почты, он лежит в `config.py`
и секретом не является. Теперь **без пароля дашборд просто не отвечает** и
объясняет, что делать. Это исправлено в сборке 31.

**Правило второе: не открывайте порт 5000 всему интернету.** В правиле
брандмауэра Google Cloud укажите **только свой домашний IP-адрес** в поле
«Диапазоны источников» вместо `0.0.0.0/0`.

Помните: пароль передаётся по обычному HTTP, то есть по дороге его видно.
Ограничение по адресу — не перестраховка, а необходимая часть защиты.

Если возиться с брандмауэром не хочется — **не открывайте порт вообще**.
Смотрите дашборд через удалённый рабочий стол, а отчёты — через журнал в
облаке.

## Что ещё изменится после переезда

**Время сервера.** У облачной машины часовой пояс обычно UTC, а не ваш. На
проверку «рынок закрыт или неликвиден» это **не влияет**: она сделана
специально без часов и часовых поясов (см. `market_hours.py`). А вот
расписание на вкладке «Календарь» будет показывать время сервера — не
пугайтесь.

**Задержка до брокера.** Из дата-центра Google до сервера брокера может быть
дальше, чем из вашего дома. Для скальпинга это заметно. Поэтому регион и
выбирайте по брокеру, а не по себе.

**Программа продолжит обновляться.** Кнопка обновления на вкладке «Система»
работает на сервере точно так же.
