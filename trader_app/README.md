# Trader — управление счетами MT5 без открытия MetaTrader

Программа для Windows: подключает несколько торговых счетов MetaTrader 5,
показывает их состояние в одном окне и позволяет закрывать сделки, не заходя
в сам терминал.

> Работайте только на **демо-счетах**, пока не убедитесь в поведении системы.

---

## Что умеет

- **Несколько счетов одновременно.** На каждый счёт — свой процесс и своя
  копия терминала, поэтому счета работают параллельно и не мешают друг другу.
- **Пароли зашифрованы средствами Windows** (DPAPI) и привязаны к вашей
  учётной записи. Если файл со счетами скопируют на другой компьютер,
  пароли не расшифруются. Вводить мастер-пароль не нужно, поэтому программа
  может запускаться автоматически.
- **Живое состояние**: средства, плавающий результат, изменение за день,
  список открытых позиций с ценами и стопами.
- **Закрытие сделок из окна**: все, только прибыльные, только убыточные,
  одну по двойному щелчку.
- **Аварийная кнопка** — закрыть всё на всех счетах сразу.
- **Дневной лимит убытка** на каждый счёт: при достижении программа
  закрывает позиции и больше не открывает сделки до следующего дня.

---

## Установка

1. Установите Python 3.11+ с [python.org](https://www.python.org/downloads/),
   при установке отметьте **«Add Python to PATH»**.
2. Установите зависимости:
   ```bat
   cd путь\к\проекту\trader_app
   pip install -r requirements.txt
   ```
3. Запустите `install\start-trader.bat` (или `python main.py`).

Интерфейс использует tkinter — он входит в стандартную поставку Python,
отдельно ставить ничего не нужно.

## Как добавить счёт

Нажмите **+ Добавить** и заполните поля:

| Поле | Что вписать |
|---|---|
| Название | Любое понятное вам, например «Демо Exness» |
| Номер счёта | Логин, который дал брокер |
| Пароль | Пароль от торгового счёта (сохранится зашифрованным) |
| Сервер брокера | Точное имя сервера, например `Exness-MT5Trial` |
| Путь к terminal64.exe | Копия MT5 для этого счёта. Пусто = терминал по умолчанию |
| Инструменты | Через запятую: `EURUSD, XAUUSD` |
| Риск на сделку, % | Доля средств под риском в одной сделке |
| Макс. позиций | Ограничение одновременных сделок |
| Дневной лимит убытка, % | При достижении торговля останавливается до завтра |
| Интервал опроса, мс | Как часто читать состояние (см. ниже) |

Имя сервера можно посмотреть в самом MetaTrader: **Файл → Открыть счёт**,
либо в письме от брокера.

---

## Важно: несколько счетов = несколько копий MetaTrader

Один терминал MT5 может торговать **только одним счётом одновременно** — это
ограничение самого MetaTrader, обойти его программно нельзя.

Чтобы счета работали параллельно, установите отдельную копию терминала на
каждый счёт (портативный режим) и укажите путь к `terminal64.exe` в настройках
счёта. Практический предел — около 32 копий, реально меньше из-за памяти.

Если указать один и тот же терминал для нескольких счетов, они будут мешать
друг другу: работать будет только тот, кто вошёл последним.

---

## Про интервал опроса

Минимум — 10 мс, по умолчанию 100 мс.

Более частый опрос **не даст выигрыша**: один запрос к MT5 сам занимает
примерно 0.1–1 мс, а котировки от брокера приходят в лучшем случае несколько
раз в секунду. Опрос каждые 100 мс — это 10 проверок в секунду, то есть уже
чаще, чем меняются сами цены. Интервал в доли миллисекунды просто займёт ядро
процессора на 100% без всякой пользы.

## Безопасность

- Пароли **никогда** не хранятся открытым текстом. В `accounts.json`
  лежит только зашифрованное значение в поле `password_encrypted`.
- Шифрование привязано к вашей учётной записи Windows: на другом компьютере
  или под другим пользователем файл не расшифруется.
- Файл `accounts.json` внесён в `.gitignore` и не попадает в репозиторий.
- Программа не открывает никаких сетевых портов наружу.

Если запустить программу не на Windows (например для тестов), шифрование
недоступно — в этом случае в окне добавления счёта прямо написано, что
пароли не защищены.

## Проверка

```bash
bash tests/run_all.sh
```

64 теста по этой программе: шифрование и расшифровка паролей (включая юникод
и длинные строки), отсутствие пароля в файле на диске, проверка данных счёта,
устойчивость к испорченному файлу, запуск и остановка процессов, доставка
команд, подсчёт сводки, определение зависшего процесса.

MetaTrader для тестов не нужен — процессы счетов подменяются заглушками.

## Известные ограничения

1. **Только Windows.** Пакет `MetaTrader5` существует лишь под Windows, и
   шифрование DPAPI — тоже Windows-технология.
2. **Автоторговля пока не включена.** Сейчас программа показывает состояние
   и закрывает сделки по вашей команде; открытие сделок по сигналу — следующий
   шаг (место под него в коде уже есть: команда `CMD_OPEN` и флаг
   `autotrade` в процессе счёта).
3. **Дневной лимит убытка** считается процессом счёта от средств на момент
   первого запуска в этот день. При перезапуске программы отсчёт начнётся
   заново — в советнике AI Scalper Pro эта же задача решена через глобальные
   переменные терминала, здесь это ещё предстоит сделать.
4. Графиков в окне пока нет — только числа и таблица позиций.
