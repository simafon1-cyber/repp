# DualGuard EA — торговая система для MetaTrader 5 (EURUSD + XAUUSD, M5)

Советник для **демо-счёта** MetaTrader 5, работающий на двух графиках M5
(EURUSD и XAUUSD) с **общим контролем риска** через Global Variables
терминала и **ИИ-ограничителем** (локальный Python-мост + Claude).

> **Это не обещание прибыли.** Приоритет системы — ограничение риска,
> прозрачность и тестируемость. Запускайте только на демо-счёте, пока
> лично не убедитесь в поведении системы. Торговля CFD/Forex связана
> со значительным риском.

Основано на изучении открытого проекта
[Nyao Scalper MT5](https://github.com/elrizwiraswara/nyao_scalper_mt5)
(BSD 3-Clause). Мартингейл, hedge chain и recovery sizing **полностью
удалены** — подробности в [NOTICE.md](NOTICE.md).

## Как устроена система

```
┌─ MetaTrader 5 ──────────────────────────────────────────┐
│  График EURUSD M5          График XAUUSD M5             │
│  DualGuardEA (magic 510001) DualGuardEA (magic 510002)  │
│        │    └──── общий риск: Global Variables ────┘    │
│        │ WebRequest раз в 30 минут                      │
└────────┼────────────────────────────────────────────────┘
         ▼
  http://127.0.0.1:8080  ← Python-мост (FastAPI)
         │  данные H1/H4, DXY, US10Y, новости
         ▼
      Claude (Anthropic API) — только ограничивает риск
```

Ключевые принципы:

- Вход оценивается **только по закрытой свече M5**; сопровождение позиций
  (трейлинг, безубыток) работает на каждом тике.
- Лот считается **от процента риска и фактической дистанции Stop Loss**
  через `OrderCalcProfit` — корректно и для EURUSD, и для XAUUSD у любого
  брокера. Лот **никогда не увеличивается после убытка**.
- ИИ может только **запрещать и уменьшать**: блокировать входы, запрещать
  направление, уменьшать лот (множитель 0.0–1.0). ИИ не даёт сигналов,
  не управляет стопами и не может обойти локальные фильтры.
- Оба графика видят **общее состояние риска**: дневной лимит убытка,
  общий корзинный стоп и корзинную фиксацию прибыли.

## Установка: шаг за шагом

### Шаг 1. Установите советник

1. Откройте MetaTrader 5 → меню **Файл → Открыть каталог данных**.
2. Скопируйте файл `mql5/DualGuardEA.mq5` в папку `MQL5\Experts\`.
3. Откройте MetaEditor (клавиша F4 в терминале), найдите файл слева
   в дереве, откройте его и нажмите **F7 (Компилировать)**.
   Должно быть: *0 errors*. Если есть ошибки — пришлите их текст.

### Шаг 2. Разрешите WebRequest

1. В терминале: **Сервис → Настройки → Советники**.
2. Поставьте галочки «Разрешить алготрейдинг» и
   «Разрешить WebRequest для перечисленных URL».
3. Добавьте в список адрес: `http://127.0.0.1:8080`

Без этого советник не сможет обращаться к мосту (в журнале будет
подсказка об этом).

### Шаг 3. Установите Python и зависимости моста

Мост должен работать **на том же компьютере (Windows)**, где запущен
MetaTrader 5 — библиотека `MetaTrader5` подключается к локальному
терминалу.

1. Установите Python 3.11+ с [python.org](https://www.python.org/downloads/)
   (при установке отметьте «Add Python to PATH»).
2. В командной строке (cmd) выполните:

```bat
cd путь\к\проекту\bridge
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

### Шаг 4. Настройте ключ API и конфиг

1. Скопируйте `bridge\.env.example` в `bridge\.env` и впишите ключ:
   `ANTHROPIC_API_KEY=sk-ant-...`
   Ключ можно получить на [console.anthropic.com](https://console.anthropic.com).
   Файл `.env` внесён в `.gitignore` и не попадает в git.
2. Скопируйте `bridge\config.example.toml` в `bridge\config.toml`.
   При необходимости поменяйте имя модели, имена символов вашего брокера
   (например `EURUSD.a`), список кандидатов для DXY/US10Y.

### Шаг 5. Запустите мост

```bat
cd путь\к\проекту\bridge
venv\Scripts\activate
python main.py
```

Проверка: откройте в браузере `http://127.0.0.1:8080/health` — должен
вернуться JSON со `"status": "ok"`. Мост слушает **только 127.0.0.1**
и недоступен из сети.

### Шаг 6. Настройте два графика

1. Откройте график **EURUSD, период M5**. Перетащите на него DualGuardEA.
   Параметры можно оставить по умолчанию: профиль `auto` сам определит
   EURUSD и возьмёт MagicNumber **510001**.
2. Откройте график **XAUUSD, период M5**. Перетащите советник и туда.
   Профиль `auto` определит золото, MagicNumber будет **510002**.
3. Убедитесь, что в углу каждого графика активен алготрейдинг (кнопка
   «Алготрейдинг» в терминале включена).

На каждом графике советник рисует панель состояния: профиль, состояние
общего риска, режим ИИ и возраст кэша, последняя причина блокировки входа.

### Шаг 7. Безопасный запуск на демо

1. Обязательно **демо-счёт**.
2. Первые дни держите `InpEnableAI = false` (чистая локальная логика) или
   включите в конфиге моста `[mock] enabled = true` — так вы проверите
   механику без затрат на API.
3. Следите за вкладкой «Эксперты» в терминале: советник пишет причину
   каждого разрешённого и заблокированного входа.
4. Проверьте общий риск: откройте обе позиции (или дождитесь), убедитесь,
   что панель на обоих графиках показывает один и тот же «баланс дня».

## Входные параметры советника

Полная таблица всех параметров — в [docs/PARAMETERS.md](docs/PARAMETERS.md).
Самое важное:

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `InpProfile` | auto | Профиль: auto / eurusd / gold. При несоответствии символу торговля запрещается с записью в журнал |
| `InpMagicNumber` | 0 (авто) | 510001 для EURUSD, 510002 для XAUUSD |
| `InpRiskPercentEURUSD` | 0.5 % | Риск на сделку EURUSD от equity |
| `InpRiskPercentGold` | 0.3 % | Риск на сделку XAUUSD от equity |
| `InpDailyLossLimitPercent` | 3 % | Общий дневной лимит убытка (баланс начала дня vs equity). Закрывает всё и блокирует до следующего дня |
| `InpSharedBasketStopPercent` | 5 % | Общий корзинный стоп по плавающему убытку обоих инструментов |
| `InpBasketTakeProfitPercent` | 0.5 % | Корзинная фиксация прибыли: все позиции робота закрываются разом при суммарном плюсе (0 = выкл) |
| `InpMaxPositionsPerSymbol` | 3 | Лимит открытых позиций на инструмент |
| `InpMaxPortfolioRiskPercent` | 2 % | Лимит суммарного открытого риска портфеля |
| `InpEntryMode` | тренд | Режим входа: тренд (EMA+RSI), отбой Боллинджера, оба |
| `InpUseH1TrendFilter` | true | Фильтр направления H1: EMA 50/200 |
| `InpEnableAI` | true | ИИ-ограничитель через мост |
| `InpBridgeFailureMode` | pause | Если мост ни разу не ответил: pause — не торговать, baseline — торговать по локальной логике |

## Режимы тестирования

1. **ИИ выключен**: `InpEnableAI = false` — только локальная логика.
   Единственный режим для тестера стратегий (в тестере WebRequest
   недоступен, советник отключает ИИ сам и пишет об этом в журнал).
2. **Mock-ответ ИИ**: в `config.toml` моста `[mock] enabled = true` —
   мост отвечает фиксированным ответом без обращения к API. Не нужен ключ.
3. **Запись и воспроизведение**: все запросы/ответы пишутся в
   `bridge/logs/bridge-ГГГГММДД.jsonl`. Для воспроизведения укажите файл
   журнала в `[replay]` конфига — мост будет отдавать записанные ответы.

## Автоматические проверки

В проекте есть свой набор тестов — 135 проверок. Запуск одной командой
(нужны `g++` и Python 3.11+; на Windows — через WSL или Git Bash):

```bash
bash tests/run_all.sh
```

Что именно проверяется:

| Проверка | Что делает |
|---|---|
| `tests/lint_mq5.py` | Статический анализ `.mq5` без MetaEditor: баланс скобок, запись в `input`-параметры (ошибка компиляции MQL5), опечатки в именах функций API |
| `tests/test_logic.cpp` | 84 теста логики советника. Функции берутся **прямо из `DualGuardEA.mq5`** (см. `extract_functions.py`), поэтому тестируется настоящий код: расчёт лота для EURUSD и золота, округление до шага брокера, сессии с летним временем, фильтр конца недели, разбор ответа моста, ИИ-ограничитель |
| `tests/test_bridge.py` | 51 тест моста: валидация ответа Claude, раздельный кэш EURUSD/XAUUSD, срок жизни кэша, режим воспроизведения, endpoints, безопасность конфига |

Тесты проверены «мутациями»: в код намеренно вносились ошибки, и тесты их
находили — то есть это не формальность.

Что проверить руками перед реальным запуском (чек-лист):

- [ ] Компиляция `DualGuardEA.mq5` в MetaEditor: 0 ошибок.
- [ ] `python main.py` запускается, `/health` отвечает.
- [ ] Остановите мост: через 45 минут панель советника должна показать
      «кэш устарел → chaos», новые входы блокируются (режим pause).
- [ ] Кэш раздельный: `/regime?symbol=EURUSD` и `/regime?symbol=XAUUSD`
      логируются отдельными строками в журнале моста.
- [ ] Оба графика показывают один «баланс дня» — общий риск работает.

## Известные ограничения

1. **Тестер стратегий MT5** не поддерживает: WebRequest (ИИ отключается
   автоматически), экономический календарь (фильтр новостей не работает,
   советник пишет предупреждение), одновременный запуск двух графиков
   (общий риск полноценно проверяется только на демо в реальном времени).
2. **Календарь новостей MT5** у некоторых брокеров отключён. Для золота
   в этом случае новые входы блокируются (безопасный отказ); это
   переопределяется параметром `InpNewsFailOpen` (не рекомендуется).
3. **DXY и US10Y** есть не у всех брокеров. Если символы не найдены, мост
   честно передаёт Claude «данные недоступны» — ничего не выдумывается.
4. Мост и терминал должны работать **на одной Windows-машине**.
5. Время сессий считается от `TimeGMT()` с автоматическим учётом летнего
   времени Лондона/Нью-Йорка. В тестере используется ручное смещение
   `InpTesterUTCOffsetHours` (по умолчанию UTC+2 — типичный сервер).
6. Корзинная фиксация прибыли и корзинный стоп закрывают позиции
   рыночными ордерами — при быстром рынке итоговая сумма может немного
   отличаться от порога (проскальзывание).
