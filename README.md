# Торговые системы для MetaTrader 5

В репозитории три самостоятельных проекта и общий набор проверок.

| Проект | Где лежит | Что это |
|---|---|---|
| **AI Scalper Standalone** | [`ai_scalper_standalone/`](ai_scalper_standalone/) | Основной проект: программа на Python с окном Windows. Торгует сразу по списку инструментов, подключаясь к MT5 напрямую, работает с несколькими счетами, собирается в `.exe` |
| **AI Scalper Pro** | [`ai_scalper_pro/`](ai_scalper_pro/) | Советник MQL5, с которого портирована логика программы. Доработан: исправлен расчёт риска, добавлены быстрая фиксация прибыли и выход по времени |
| **DualGuard EA** | [`mql5/`](mql5/) | Советник на два графика (EURUSD + XAUUSD) с общим контролем риска и ИИ-ограничителем. Мост к Claude теперь встроен в программу (папка [`bridge/`](bridge/) оставлена как отдельный вариант). Здесь же сервис `CalendarExport` — бесплатный календарь новостей из терминала |

| Служебное | Где лежит | Для чего |
|---|---|---|
| Установщики | [`install/`](install/) | Запасные `.bat` для Windows. Обычно не нужны: программа ставит советники и сервис календаря в MT5 сама при первом запуске |
| Проверки | [`tests/`](tests/) | 3115 автоматических тестов, запуск: `bash tests/run_all.sh` |
| Проверка сторонним ИИ | [`ДЛЯ_ПРОВЕРКИ_ДРУГИМ_ИИ.md`](ДЛЯ_ПРОВЕРКИ_ДРУГИМ_ИИ.md) | С чего начать чтение чужому ИИ: устройство проекта, правила владельца, честный список слабых мест |
| Документация | [`docs/`](docs/) | [Все параметры программы](docs/ПАРАМЕТРЫ.md) — что делает каждый и что будет, если изменить. Плюс таблица параметров DualGuard EA |
| Установка на сервер | [`deploy/`](deploy/) | Один скрипт для Google Cloud Shell: создаёт машину с Windows, сам ставит MetaTrader и программу, включает автозапуск |
| Работа на сервере | [`docs/ОБЛАКО.md`](docs/ОБЛАКО.md) | Перенос на облачную машину, чтобы бот работал круглосуточно без домашнего компьютера: что подходит, сколько стоит, как защитить дашборд |

## Чего в репозитории нет и почему

**Собранный `.exe`, папки `build`, `dist`, `__pycache__`.** Это результат
сборки, а не исходный код. Git хранит все версии файлов навсегда, а двоичные
файлы почти не сжимаются между сборками — каждая пересборка добавляла бы
ещё ~55 МБ в историю безвозвратно.

Вместо этого настроена автоматическая сборка на серверах GitHub: вкладка
**Actions** → «Сборка AI_Scalper_Pro.exe» → **Run workflow**. Готовый файл
появится в разделе Artifacts. По тегу вида `v1.0` сборка публикуется в
**Releases**, где вложения не входят в историю репозитория.

**Руками туда ходить больше не нужно.** Программа умеет сама заказать сборку,
дождаться её, скачать и поставить — вкладка «Система» → «Обновление из
GitHub» → **«Обновить всё сейчас»**. Подробнее — в
[ОПИСАНИЕ.md](ОПИСАНИЕ.md#обновление-без-переустановки).

**Файлы с секретами и личными данными:** `config.py` (ключи API, соль, хэш
пароля), `.login_remember`, `scalper.log`, `trades_log.csv`, `accounts.json`,
`telegram_session`. Все они в `.gitignore`. Историю сделок при желании можно
выкладывать в закрытый репозиторий отдельно и осознанно — вкладка «Система» →
«Журнал сделок в облаке». Туда уходят только сделки: ни паролей, ни ключей, ни
токенов. В репозитории лежит только
[`config.py.example`](ai_scalper_standalone/config.py.example) — та же
структура с пустыми полями, которые заполняются через интерфейс программы.

**Приватный режим.** Если репозиторий закрытый и вы хотите хранить свои
настройки и ключи прямо в нём — запустите `install/enable-private-mode.bat`.
Он включит `PRIVATE_MODE` (секреты перестанут шифроваться) и разрешит git
сохранять `config.py`. При этом `telegram_session`, `accounts.json`, журналы и
CSV сделок остаются вне git **всегда**: закрытый репозиторий не повод класть
туда действующие пропуска. Подробнее — в
[`ai_scalper_standalone/README.md`](ai_scalper_standalone/README.md).

## Предупреждение

Это не обещание прибыли. Приоритет всех трёх проектов — ограничение риска,
прозрачность и тестируемость. Работайте на **демо-счёте**, пока лично не
убедитесь в поведении системы. Торговля CFD и Forex связана со значительным
риском потери средств.
