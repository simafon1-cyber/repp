# AI Scalper Pro — доработанная версия

Ваш советник с исправленным расчётом риска, быстрой фиксацией прибыли,
выходом по времени и автозапуском моста.

> Работайте только на **демо-счёте**, пока лично не убедитесь в поведении
> системы. Торговля CFD/Forex связана со значительным риском.

---

## Что изменилось

### 1. Исправлен расчёт риска (три ошибки)

**Минимальный лот больше не ломает лимит риска.** Раньше, если посчитанный
по риску лот получался меньше минимального у брокера, советник **всё равно
открывал сделку** минимальным лотом. Пример: счёт $100, риск 0.3% = $0.30,
стоп 100 пунктов — расчётный лот 0.003, а открывался 0.01, то есть реальный
риск $1.00 вместо $0.30, **втрое больше заявленного**. Теперь такая сделка
не открывается, а причина пишется в журнал.

Если вас это не устраивает, старое поведение возвращается параметром
`AllowMinLotOverRisk = true`.

**Объём больше не занижается на шаг.** Формула `MathFloor(lot/step)*step`
из-за двоичной арифметики давала 0.28 вместо 0.29. Я проверил численно:
на случайных значениях шаг терялся примерно в **7% случаев**. Добавлена
функция `FloorVolumeToStep` с поправкой; она же учитывает брокеров с шагом
лота 0.001.

**Деньги считаются точно.** Все денежные расчёты (риск сделки, суммарный
риск портфеля) переведены с `SYMBOL_TRADE_TICK_VALUE` на `OrderCalcProfit`.
Tick value работает для EURUSD, но на золоте и кроссах у части брокеров он
неточен или обновляется с задержкой — риск считался неверно именно там,
где цена ошибки выше всего.

### 2. Быстрая фиксация прибыли ступенями

Было: одно частичное закрытие по фиксированным пунктам (по умолчанию
выключено). 150 пунктов на EURUSD и на золоте — совершенно разные движения,
поэтому на разных инструментах вело себя по-разному.

Стало: **две ступени, пороги в ATR** — одинаково работают на любом
инструменте. Часть прибыли снимается рано, остаток продолжает идти под
трейлингом. Риск при этом не растёт — объём только уменьшается.

### 3. Выход по времени

Раньше выхода по времени не было вообще: сделка могла висеть часами, пока
её не выбьет стоп или трейлинг. Для скальпинга это главный источник
«зависших» убытков.

Теперь два уровня:

- **Мягкий выход** (по умолчанию 20 минут): время вышло и сделка в плюсе —
  фиксируем прибыль. Если сделка прямо сейчас на пике и продолжает расти,
  её не трогаем (параметр `SoftExitKeepRunning`), её ведёт трейлинг.
- **Жёсткий выход** (по умолчанию 60 минут): закрываем в любом случае,
  даже в минусе. Лучше зафиксировать небольшой минус, чем ждать полный стоп.

Каждое закрытие пишется в журнал с причиной и временем удержания.

### 4. Автозапуск моста

Мост теперь запускается сам при входе в Windows, в фоне, без чёрного окна.
Ключ API вынесен из кода в файл `.env`. Добавлены `/health` для проверки и
журнал `bridge.log`.

## Установка

### Советник

Сам проект может лежать где угодно (например `D:\Big Projeckt`) — MetaTrader
читает советники **только из своего каталога данных**, поэтому файлы нужно
скопировать туда.

**Проще всего:** запустите `install\install-scalper.bat`. Он найдёт все
установленные терминалы MetaTrader 5 и скопирует туда все 12 файлов
советника в папку `MQL5\Experts\AI_Scalper_Pro\`.

**Вручную:** меню **Файл → Открыть каталог данных**, создайте папку
`MQL5\Experts\AI_Scalper_Pro\` и скопируйте туда **все** файлы `.mq5` и
`.mqh` из папки `ai_scalper_pro`. Важно скопировать все — они подключаются
друг к другу через `#include` и должны лежать вместе.

Затем в терминале: **F4** → откройте `AI_Scalper_Pro.mq5` → **F7**
(компиляция). Должно быть *0 errors*.

### Нужен ли вообще ключ API

**Нет, для начала не нужен.** Советник торгует по своему сигналу, а внешний
источник только добавляет или отнимает баллы. Без ключа мост отдаёт
`neutral`, что меняет оценку ровно на 0 — торговля идёт как обычно.

Так же система ведёт себя, если мост вообще не запущен: в журнал пишется
предупреждение, и советник продолжает работать по своему скорингу.

Хотите совсем отключить внешний сигнал — поставьте `UseExternalSignal = false`.

### Где взять ключ (когда решите подключить)

Мост берёт данные с [Twelve Data](https://twelvedata.com) — там есть
бесплатный тариф.

1. Откройте https://twelvedata.com и нажмите **Get Free API Key** (регистрация
   по email).
2. Подтвердите email.
3. В личном кабинете откройте раздел **API Keys** и скопируйте ключ.
4. Вставьте его в файл `ai_scalper_pro\bridge\.env`:
   ```
   TWELVEDATA_API_KEY=ваш_ключ
   ```
5. Проверьте: `http://127.0.0.1:8787/health` должен показать
   `"api_key_present": true`.

**Про лимит запросов.** У бесплатного тарифа есть суточный лимит (порядок —
несколько сотен запросов; точные цифры смотрите на сайте, они меняются).
Советник опрашивает мост раз в `ExternalSignalRefreshSec` секунд:

| Интервал | Запросов в сутки при работе 24/7 |
|---|---|
| 60 сек (по умолчанию) | до 1440 |
| 180 сек | до 480 |
| 300 сек | до 288 |

Если упрётесь в лимит — увеличьте `ExternalSignalRefreshSec` до 180. Для
сигнала, который и так обновляется по 15-минутному RSI, это ничего не портит.

### Мост с автозапуском

1. Установите Python 3.11+ с [python.org](https://www.python.org/downloads/),
   при установке отметьте **«Add Python to PATH»**.
2. Установите зависимости:
   ```bat
   cd путь\к\проекту\ai_scalper_pro\bridge
   pip install -r requirements.txt
   ```
3. Запустите `install\enable-bridge-autostart.bat` — мост будет стартовать
   при каждом входе в Windows и запустится сразу.
4. Впишите ключ [Twelve Data](https://twelvedata.com) (есть бесплатный тариф)
   в файл `ai_scalper_pro\bridge\.env`:
   ```
   TWELVEDATA_API_KEY=ваш_ключ
   ```
5. Проверьте: откройте `http://127.0.0.1:8787/health` — должно быть
   `"status": "ok"` и `"api_key_present": true`.
6. В MT5: **Сервис → Настройки → Советники** → разрешить WebRequest и
   добавить `http://127.0.0.1:8787`.

Отключить автозапуск: `install\disable-bridge-autostart.bat`
Запустить мост вручную: `install\start-scalper-bridge.bat`

## Новые параметры

### Быстрая фиксация прибыли

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `UseQuickProfit` | true | Включить ступенчатую фиксацию по ATR |
| `QuickProfit1ATR` | 0.5 | Ступень 1: прибыль в ATR, при которой снимаем часть |
| `QuickProfit1Percent` | 40 | Ступень 1: сколько % объёма закрыть |
| `QuickProfit2ATR` | 1.0 | Ступень 2: прибыль в ATR (0 = ступень выключена) |
| `QuickProfit2Percent` | 40 | Ступень 2: сколько % оставшегося объёма закрыть |

### Выход по времени

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `UseTimeExit` | true | Включить закрытие по времени |
| `SoftExitMinutes` | 20 | Через сколько минут фиксировать плюс |
| `SoftExitMinProfitPoints` | 0 | Мин. прибыль в пунктах для мягкого выхода (0 = любой плюс) |
| `SoftExitKeepRunning` | true | Не закрывать, если сделка сейчас на пике и растёт |
| `HardExitMinutes` | 60 | Через сколько минут закрыть любую сделку (0 = выкл) |

### Внешний сигнал

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `UseExternalSignal` | true | Использовать мост внешнего сигнала |
| `ExternalSignalRefreshSec` | 60 | Как часто опрашивать мост, секунд. Больше = экономнее по лимиту API |

### Честность расчёта риска

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `AllowMinLotOverRisk` | false | Разрешить мин. лот, даже если он превышает заданный риск |

## Как настроить под себя

**Хочу фиксировать ещё чаще:** уменьшите `QuickProfit1ATR` до 0.3 и
`SoftExitMinutes` до 10.

**Слишком рано выходит, движения не доезжают:** увеличьте `QuickProfit1ATR`
до 0.8, `SoftExitMinutes` до 40, `HardExitMinutes` до 120.

**Хочу только выход по времени, без частичных закрытий:**
`UseQuickProfit = false`, `UseTimeExit = true`.

**Хочу вернуть как было:** `UseQuickProfit = false`, `UseTimeExit = false`.
Исправления расчёта риска при этом останутся — они не отключаются, потому
что это исправление ошибок, а не новая возможность.

## Проверка изменений

В проекте есть автоматические тесты (нужны `g++` и Python 3.11+):

```bash
bash tests/run_all.sh
```

Что проверяется по этому проекту:

- **Статический анализ** всех 12 файлов: баланс скобок, запись в
  `input`-параметры, опечатки в вызовах функций MQL5.
- **22 теста расчёта риска** — функции берутся прямо из `RiskManager.mqh`,
  поэтому тестируется настоящий код: отказ при превышении риска мин. лотом,
  граница этого отказа, округление объёма, снижение риска после серии
  убытков, расчёт для золота с другим размером контракта.
- **24 теста моста**: разбор символов с суффиксами брокера, чтение ключа
  из `.env`, endpoints, безопасность.

## Что осталось как было

Эти вещи я не трогал — они работают и менять их без вашего решения не стоит:

- Скоринг сигналов 0–100 и все его веса
- Профили риска (Консервативный / Сбалансированный / Агрессивный / Истеричка)
- Новостной режим и встроенный календарь MT5
- Break Even, ATR-трейлинг, ступенчатый Profit Lock
- Панель на графике и CSV-лог сделок

## Известные ограничения

1. **Общий риск не разделяется между графиками.** `CountOpenPositions` и
   `GetOpenRiskPercent` считают только по текущему символу — на двух
   графиках получится два независимых лимита. Решается через Global
   Variables (как сделано в DualGuard EA), но это отдельная задача.
2. **Внешний сигнал задаёт направление сделки.** Мост возвращает
   `buy`/`sell`, и это подмешивается в score. То есть внешний источник —
   не только ограничитель, но и источник сигнала.
3. **Профиль «Истеричка»** отключает фильтры времени, новостей и
   волатильности. Аварийные стоп-краны при этом работают.
4. Компиляцию в MetaEditor нужно выполнить самостоятельно — это
   Windows-программа.
