# Сборка desktop-приложения (.exe) и установщика Windows

Важно понимать: собрать настоящий Windows `.exe`/установщик можно **только
на самом Windows-компьютере** (PyInstaller не умеет собирать exe для Windows
с других систем). Поэтому все шаги ниже выполняются у тебя на компьютере,
в папке проекта (`D:\Big Projeckt`) — я подготовил всё так, чтобы это было
буквально "запустил файл — получил результат", без ручной возни.

## Что получится в итоге

- `dist\AI_Scalper_Pro.exe` — готовая программа. Можно просто скопировать
  куда угодно (флешка, другой компьютер) и запускать — Python отдельно
  устанавливать НЕ нужно, всё уже внутри.
- (по желанию) `installer_output\AI_Scalper_Setup.exe` — normal Windows-
  установщик: запускаешь, жмёшь "Далее", получаешь программу в Пуске и
  ярлык на Рабочем столе, как у любой обычной программы.

## Шаг 1 — собрать AI_Scalper_Pro.exe

1. Убедись, что Python 3.10+ установлен (`python --version` в cmd).
2. В папке `D:\Big Projeckt` дважды кликни **`build_exe.bat`**
   (или запусти из cmd: `cd /d "D:\Big Projeckt" && build_exe.bat`).
3. Скрипт сам поставит зависимости и соберёт программу. Это займёт пару
   минут. В конце появится `dist\AI_Scalper_Pro.exe` — можешь сразу
   запустить его двойным кликом и проверить, что всё работает
   (окно программы, кнопка "Открыть дашборд" и т.д.).

Готово — этого шага уже достаточно, чтобы пользоваться программой как
обычным Windows-приложением. Шаг 2 нужен только если хочешь полноценный
установщик с ярлыками в Пуске (необязательно).

## Шаг 2 (по желанию) — собрать установщик AI_Scalper_Setup.exe

1. Скачай и установи **Inno Setup** (бесплатно): https://jrsoftware.org/isdl.php
2. Открой файл `installer.iss` (из папки проекта) через Inno Setup Compiler
   — он должен открыться сам при установке Inno Setup, либо через
   "Открыть с помощью" → Inno Setup Compiler.
3. Нажми **Compile** (или F9).
4. Готовый установщик появится в `installer_output\AI_Scalper_Setup.exe`.
5. Раздай этот файл (себе на другой компьютер, знакомым и т.д.) — запуск
   как у обычного установщика: "Далее → Далее → Установить", ничего лишнего
   не спрашивает и не требует прав администратора (ставится в папку текущего
   пользователя).

## Что изменилось в последней версии

`desktop_app.py` (точка входа для сборки) с последнего билда сильно вырос —
если у тебя уже стоит старая версия `.exe`, обязательно пересобери через
`build_exe.bat` заново, иначе новые функции ниже работать не будут:

- реальные сделки (`LIVE_TRADING=True`) с ценой входа/текущей ценой/временем
  открытия в вкладке «Сделки»;
- добавление/удаление символов прямо из интерфейса;
- кнопка «Полный выход» (гарантированно завершает процесс);
- экран входа по логину/паролю перед открытием окна и автозапуск бота сразу
  после входа;
- звуковые/всплывающие уведомления, мини-график цены по символу, экспорт в
  Excel;
- вкладка «Новости» (Finnhub, универсальная архитектура провайдеров через
  `news_providers.py`) и вкладка «Chat AI»;
- переключатель Простой/Продвинутый режим интерфейса;
- шифрование секретов config.py (MT5-пароль, ключи AI/новостей) паролем
  входа, атомарная запись + резервные копии + проверка целостности файлов,
  ограничение доступа к config.py/логам через Windows ACL (см. `secure_store.py`
  / `safe_files.py`, раздел «Безопасность» в README.md);
- новая вкладка **«Настройка»** (объединяет прежние «Настройки»+«Параметры»,
  видна ВСЕГДА в обоих режимах интерфейса) — полный паритет с окном "Inputs"
  MQL5-советника: ~90 входных параметров (сгруппированы как в `config.py`)
  плюс отдельные редакторы профилей риска (`RISK_PROFILES`) и корреляций
  контекста рынка (`MARKET_CONTEXT`) по каждому символу;
- в торговую логику добавлены недостающие фичи советника: часы торговли,
  переключатель "лот без риск-расчёта", раздельные окна новостей (жёсткий
  блок / мягкий штраф score), настраиваемый таймаут AI-запроса, частичное
  закрытие позиции (см. раздел «Полный паритет с MQL5-советником» в README.md);
- новая вкладка **«Как пользоваться»** — подробная инструкция по всем
  вкладкам прямо внутри приложения, видна всегда;
- галочка **«Запомнить пароль»** на экране входа (Windows DPAPI, без новых
  зависимостей) — пароль предзаполняется при следующем запуске;
- **синхронизация с MetaTrader**: вкладка «Сделки» показывает ВСЕ позиции
  счёта (не только бота), вкладка «Лог» и экспорт в Excel подтягивают полную
  историю закрытых сделок напрямую из MT5 (см. раздел «Синхронизация с
  MetaTrader» в README.md);
- главный цикл ускорен (один запрос позиций/счёта на итерацию вместо
  отдельного на каждый символ);
- диагностика «сделки не открываются» — предупреждение на вкладке «Обзор»,
  если выключен AutoTrading / запрещена торговля на счёте / выключено
  «Разрешить автоматическую торговлю» в терминале;
- кнопка **«Закрыть ВСЕ сделки»** на вкладке «Сделки» (абсолютно все позиции
  счёта, с подтверждением);
- добавление символа на вкладке «Символы» — теперь выпадающий список,
  синхронизированный с реальными парами брокера (`mt5.symbols_get()`), вместо
  свободного текстового поля (см. разделы выше в README.md).

`requirements.txt` тоже пополнился (`requests`, `openpyxl`, `cryptography`) —
`build_exe.bat` ставит их сам на шаге 1, ничего руками доустанавливать не нужно.

## Важные детали (почему сделано именно так)

- **`config.py` НЕ встроен внутрь .exe.** Он остаётся обычным текстовым
  файлом рядом с программой — специально, чтобы работало автообновление
  настроек "на лету" (см. `USE_CONFIG_HOT_RELOAD` в README) и чтобы ты мог
  менять пары/профиль/ключи AI без пересборки программы. При установке
  через `installer.iss` он копируется один раз и больше не перезаписывается
  при переустановке (чтобы не потерять твои настройки). Пересборка через
  `build_exe.bat` теперь ведёт себя так же: если `dist\config.py` уже
  существует (то есть ты уже настраивал брокера/пары/пароль через интерфейс
  программы), скрипт его НЕ трогает — раньше он перезаписывался при каждой
  пересборке, и повторный запуск `build_exe.bat` тихо стирал твои сохранённые
  настройки.
- **Все остальные модули (риск-менеджмент, индикаторы, AI-сигнал и т.д.)
  встроены внутрь .exe** — так проще и надёжнее для конечного использования:
  один файл, ничего не потеряется и не отвяжется.
- **Веб-дашборд поднимается один раз при старте программы**, а не при каждом
  нажатии "Старт" — так что "Открыть дашборд" работает даже если бот сейчас
  остановлен (просто покажет последние известные данные).
- **Кнопка "Стоп"** не закрывает программу — только останавливает торговый
  цикл (можно снова "Старт" без перезапуска всего приложения).
- Логи пишутся в `scalper.log` рядом с программой (программа собрана с
  `--windowed`, то есть без чёрного окна консоли — весь вывод только в файл
  и в само окно приложения).

## Если сборка ругается на MetaTrader5/AI-библиотеки

Иногда PyInstaller не находит какие-то "скрытые" файлы данных у пакетов.
Если после сборки приложение не подключается к MT5 или падает при обращении
к AI — попробуй пересобрать с `--onedir` вместо `--onefile` в `build_exe.bat`
(будет папка `dist\AI_Scalper_Pro\` вместо одного файла — грузится чуть
быстрее и иногда стабильнее для таких пакетов), либо напиши мне, что именно
показывает `scalper.log` — разберёмся точечно.
